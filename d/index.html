명제와 논리 연산

참(T)과 거짓(F) 값을 다루는 논리 연산자의 규칙을 이해합니다.

기본 연산자

AND (∧) 둘 다 참일 때만 참

OR (∨) 하나라도 참이면 참

NOT (¬) 참↔거짓 반전

XOR (⊕) 서로 다를 때만 참

NAND AND의 부정 (범용 게이트)

드 모르간의 법칙

¬(A ∧ B) = ¬A ∨ ¬B
¬(A ∨ B) = ¬A ∧ ¬B

핵심 응용: 조건문 부정

// C 코드에서

논리 항등식 & 명제 법칙

항등 법칙

A ∧ T = A
A ∨ F = A

보수 법칙

A ∧ ¬A = F
A ∨ ¬A = T

분배 법칙

A∧(B∨C) = (A∧B)∨(A∧C)
A∨(B∧C) = (A∨B)∧(A∨C)

대우 / 명제

p→q 의 대우: ¬q→¬p (참값 동일)
p→q 의 역: q→p (참값 무관)

게임 이론 — 님(Nim) 게임

두 사람이 번갈아 돌을 가져가며, 마지막 돌을 가져가는 사람이 이기는 전략 게임입니다.

님 게임 필승 전략

nim_sum = pile₁ XOR pile₂ XOR ... XOR pileₙ

nim_sum ≠ 0 → 현재 플레이어 필승
nim_sum = 0 → 현재 플레이어 패배

필승 전략: XOR 후 0이 되도록 한 더미에서 제거

P-position vs N-position

P-position 이전 플레이어가 이기는 상태 → 현재 패

N-position 다음 플레이어가 이기는 상태 → 현재 승

terminal 상태 → P-position
P-position으로 이동 가능 → N-position
모든 이동이 N-position → P-position

님 게임 플레이어 (인간 vs AI)

변형: 1~K개 가져가기

필승 조건: N mod (K+1) ≠ 0
→ 상대가 m개 가져가면 (K+1-m)개 가져가 합을 K+1로 유지

그리디(Greedy) 알고리즘

매 선택 순간에 현재 가장 좋아 보이는 선택을 하는 알고리즘입니다.

그리디가 유효한 조건

탐욕 선택 속성 현재의 최선이 전체 최적에 포함됨

최적 부분 구조 부분 문제의 최적해가 전체 최적해에 포함됨

두 조건 불성립 시 DP 사용!

문제를 작은 부분 문제로 나누고, 결과를 저장해 중복 계산을 피하는 알고리즘입니다.

항목그리디DP

DP 두 가지 구현 방식

// Top-down (재귀 + 메모이제이션)
int memo[MAX];
int fib(int n) {
if(n<=1) return n;
if(memo[n]!=-1) return memo[n];
return memo[n]=fib(n-1)+fib(n-2);
}

// Bottom-up (반복문)
dp[0]=0; dp[1]=1;
for(int i=2;i<=n;i++)
dp[i]=dp[i-1]+dp[i-2];

0/1 배낭 문제 시뮬레이터

LIS (최장 증가 부분 수열) 시뮬레이터

dp[i] = i번째 원소를 마지막으로 하는 LIS 길이
dp[i] = max(dp[j]+1) for all j<i where arr[j]<arr[i]
