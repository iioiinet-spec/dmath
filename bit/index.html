1. 비트마스킹이란?

비트마스킹은 정수 하나의 각 비트 0 또는 1을 상태 정보로 사용하는 기법입니다.

예를 들어 학생 5명의 출석 여부를 저장한다고 생각해 봅시다. 출석은 1, 결석은 0으로 표현합니다.
학생번호: 4 3 2 1 0 상태: 1 0 1 1 0 mask = 10110₂
이 정수 하나만으로 0번부터 4번 학생의 상태를 모두 저장할 수 있습니다.

비트 자리의 의미

비트 위치 i값의미
0번 비트12⁰
1번 비트22¹
2번 비트42²
3번 비트82³
4번 비트162⁴
핵심 문장
1 << i 는 i번 비트만 1인 값을 만듭니다.

2. 비트마스킹 필수 공식

작업C 코드설명
i번 비트 켜기mask |= (1 << i);OR 연산으로 해당 비트를 1로 만듭니다.
i번 비트 끄기mask &= ~(1 << i);i번만 0인 마스크를 만든 뒤 AND 합니다.
i번 비트 확인if(mask & (1 << i))결과가 0이 아니면 켜져 있습니다.
i번 비트 토글mask ^= (1 << i);켜져 있으면 끄고, 꺼져 있으면 켭니다.
전체집합(1 << N) - 1N개의 비트가 모두 1인 값입니다.
모든 부분집합for(mask=0; mask<(1<<N); mask++)0부터 2ᴺ-1까지 모든 선택 상태를 순회합니다.
주의
N이 너무 크면 int 범위를 넘을 수 있으므로 큰 N에서는 1LL << N을 사용합니다.

4. 부분집합 생성 시각화

집합 원소를 입력하면 모든 부분집합을 비트마스킹으로 생성합니다.

원소가 N개라면 부분집합은 2ᴺ개입니다.

5. C언어 예제 코드

예제 1. 출석 체크

#include <stdio.h> int main() { int mask = 0; mask |= (1 << 0); mask |= (1 << 2); mask |= (1 << 4); for(int i=0; i<5; i++) { if(mask & (1 << i)) printf("%d번 학생 출석\n", i); else printf("%d번 학생 결석\n", i); } return 0; }

예제 2. 모든 부분집합 출력

#include <stdio.h> int main() { int arr[3] = {1, 2, 3}; int N = 3; for(int mask=0; mask < (1 << N); mask++) { printf("{ "); for(int i=0; i<N; i++) if(mask & (1 << i)) printf("%d ", arr[i]); printf("}\n"); } return 0; }

예제 3. 부분집합의 합

#include <stdio.h> int main() { int arr[5] = {1, 2, 3, 4, 5}; int N = 5, S = 5, count = 0; for(int mask=1; mask < (1 << N); mask++) { int sum = 0; for(int i=0; i<N; i++) if(mask & (1 << i)) sum += arr[i]; if(sum == S) count++; } printf("%d\n", count); return 0; }

6. 연습문제

문제 1. 비트 켜기

mask = 0일 때, 1번 비트와 3번 비트를 켠 결과를 10진수로 구하시오.

정답 보기

1번 비트 = 2, 3번 비트 = 8이므로 결과는 10입니다.

문제 2. 비트 확인

mask = 13일 때, 2번 비트는 켜져 있는가?

정답 보기

13 = 1101₂ 이므로 2번 비트는 1입니다. 켜져 있습니다.

문제 3. 전체집합

N = 5일 때 전체집합 마스크 (1<<N)-1의 값은?

정답 보기

2⁵ - 1 = 31입니다.

문제 4. 부분집합 개수

원소가 6개인 집합의 부분집합 개수는?

정답 보기

2⁶ = 64개입니다.

문제 5. 부분집합의 의미

집합 {A, B, C, D}에서 mask = 1010₂ 이 의미하는 부분집합은?

정답 보기

1번 B와 3번 D가 선택되어 {B, D}입니다.

문제 6. 코드 빈칸

i번 비트를 켜는 코드의 빈칸을 채우시오.

mask ___ (1 << i);
정답 보기

|= 입니다.

문제 7. 코드 빈칸

i번 비트를 끄는 코드의 빈칸을 채우시오.

mask &= ___(1 << i);
정답 보기

~ 입니다.

문제 8. 실전형

N≤20일 때 모든 부분집합을 검사하는 완전탐색이 가능한 이유를 설명하시오.

정답 보기

2²⁰ = 1,048,576개 정도라 제한 시간 안에 탐색 가능한 경우가 많기 때문입니다.
