Ⅰ-1 · 인공지능의 개념과 학습 방식

인공지능이란 무엇인가요?

현재 우리 사회는 교통, 금융, 경제, 경영 등 다양한 분야에서 인공지능의 발전과 더불어 크고 작은 변화를 겪고 있습니다. 자율 주행 자동차, 사물 인터넷, 데이터 기반 의사 결정 등 여러 분야의 기술에 인공지능이 적용되어 변화를 이끌고 있습니다.

인공지능 (Artificial Intelligence)

인간의 지능과 사고 과정을 모방하여 학습, 추론, 지각 능력 등을 실현한 기술. 1956년 미국 다트머스 대학에서 열린 학회에서 처음 등장한 용어로, 이 학회에서는 "인간이 수행하는 지적 작업 절차를 컴퓨터로 시뮬레이션한 것"이라고 정의하였습니다.

Ⅰ-1 · 인공지능의 학습 방법

인공지능은 어떻게 학습할까요?

일반적인 컴퓨터 프로그램은 주어진 데이터를 프로그래밍 언어로 작성된 명령에 따라 처리합니다. 반면 인공지능은 학습 데이터의 특징이나 규칙을 스스로 찾아내고, 새로운 데이터에 그 규칙을 적용하여 예측, 분류 등 다양한 작업을 수행합니다.

지도학습 (Supervised Learning)

정답(레이블)이 포함된 데이터를 이용하여 인공지능을 학습시키는 방법. 데이터에 포함된 다양한 속성과 정답 사이의 관계를 학습하여 규칙을 발견하고, 이 규칙으로 새로운 입력값의 정답을 예측합니다.

예시

'고양이', '개' 이미지에 레이블을 붙여 학습시키면, 인공지능은 귀의 모양·코의 크기 등 특징을 추출하여 정답과 연관 지어 학습합니다. 이후 새로운 이미지가 들어오면 특징을 분석해 개/고양이 중 어디에 속하는지 분류합니다.

비지도학습 (Unsupervised Learning)

정답(레이블)이 포함되지 않은 데이터를 이용하는 학습 방법. 정답이 없는 데이터에서 공통적인 특징을 추출하거나 비슷한 경향성을 가진 데이터끼리 무리를 짓는 방법(군집화, clustering)으로 데이터의 특성을 파악합니다.

예시

카드사가 나이와 연 지출액에 따라 고객을 군집화하면, 분석되지 않았던 데이터에서도 비슷한 특성을 가진 고객 집단을 찾아 맞춤형 서비스를 개발할 수 있습니다.

강화학습 (Reinforcement Learning)

각 시행에 따라 피드백을 받으며 학습하는 방법. 미리 데이터를 주는 것이 아니라 시행을 반복하며 성공하면 보상을 높이고, 실패하면 보상을 낮추는 방식으로 행동을 학습시킵니다.

예시

자율 주행 로봇, 자율 주차 기능, 그리고 바둑 AI 알파고가 강화학습을 활용한 대표적인 예입니다.

Ⅰ-1 · 딥러닝과 퍼셉트론

딥러닝은 무엇인가요?

인간의 뇌는 1000억 개가 넘는 뉴런으로 구성되어 있으며, 뉴런은 그물 형태로 연결된 신경망을 이루고 전기적 신호를 통해 정보를 전달합니다. 신경 세포 뉴런을 모델로 만든 것이 퍼셉트론이고, 퍼셉트론으로 구성된 신경망의 정보 전달 과정을 수학적으로 모델링한 것이 인공신경망입니다.

Ⅰ-3 · 인공지능과 빅데이터의 활용

빅데이터의 특징과 공정성

디지털 환경에서 생성되는 데이터로 수치와 문자, 영상 데이터를 포함한 대규모 데이터를 빅데이터라고 합니다. 빅데이터는 일반적으로 3가지 특징(3V)으로 설명됩니다.

📦 크기 (Volume)
데이터의 양이 매우 크다는 특징. 대규모 데이터를 의미합니다.
⚡ 속도 (Velocity)
데이터가 생성되고 처리되는 속도가 빠르다는 특징.
🌐 다양성 (Variety)
수치, 문자, 영상 등 다양한 형태의 데이터로 구성된다는 특징.

데이터 편향과 공정성

왜 중요할까?

인공지능이 학습하는 데이터에 편향이 있으면, 그 결과로 내려지는 판단도 편향될 수 있습니다. 데이터의 공정성을 지키기 위해서는 국가·기업·개인 차원에서 법과 윤리 강령을 마련하고, 공정성을 검증할 수 있는 시스템을 만들어야 합니다.

Q빅데이터를 활용하는 과정에서 데이터 공정성을 지키기 위한 노력으로 적절하지 않은 것은?
Ⅱ-1 · 텍스트 데이터의 표현 (1)

집합으로 텍스트를 표현하기

왜 집합이 필요할까?

컴퓨터는 문장과 단어로 이루어진 텍스트 데이터를 사람처럼 글자 형태로 인식할 수 없습니다. 컴퓨터가 데이터를 인식하게 하려면, 데이터를 수와 수학 기호를 이용하여 표현해야 합니다. 그 첫 번째 도구가 바로 집합입니다.

집합의 기본 개념

집합 (Set)

주어진 기준에 의하여 그 대상을 분명하게 정할 수 있을 때, 그 대상들의 모임을 집합이라고 하며, 집합을 이루는 대상 하나하나를 원소라고 합니다.

표현법설명예시
원소나열법{ } 안에 모든 원소를 나열{2, 4, 6, 8, 10}
조건제시법원소들의 공통된 성질을 제시{x | x는 10 이하의 짝수}

집합의 연산

∪
합집합 A∪B
A에 속하거나 B에 속하는 모든 원소로 이루어진 집합
∩
교집합 A∩B
A에 속하면서 B에도 속하는 모든 원소로 이루어진 집합

예를 들어 A = {1, 2, 3, 4}, B = {1, 3, 5, 7, 9}일 때

A∪B = {1, 2, 3, 4, 5, 7, 9}
A∩B = {1, 3}
Q두 집합 A={2,4,6,8,10}, B={0,4,8,12}에 대하여 A∩B는?
Ⅱ-1 · 텍스트 데이터의 표현 (2)

텍스트를 단어집합으로 만들기

다음은 한 음식점을 방문한 사람들의 댓글입니다. 이 텍스트를 집합으로 표현해 봅시다.

댓글내용
A분위기도 신선한 재료도 좋다.
B맛은 보통이고 분위기는 최고예요.
C멋있는 분위기! 최고의 재료!

텍스트 전처리 2단계

① 단어 분리
띄어쓰기를 기준으로 문장을 단어별로 분리합니다.
② 불용어 제거
의미 분석에 불필요한 조사·접미사·구두점(불용어)을 제거하고 원형으로 바꿉니다.
불용어(Stopwords)란?

문장에서 의미를 분석하는 데 불필요한 단어. 주로 조사, 접미사, 접속사, 구두점 등을 의미합니다. 예) '분위기도', '분위기는' → 조사를 제거하고 '분위기'로 통일.

전처리 결과 → 단어집합

불용어를 제거하고 남은 단어를 원소로 하는 집합을 각각 만들면:

A = {분위기, 신선하다, 재료, 좋다}
B = {맛, 보통, 분위기, 최고}
C = {멋있다, 분위기, 최고, 재료}
전체 단어집합 X

세 집합의 합집합 A∪B∪C를 집합 X라고 하면,

X = {분위기, 신선하다, 재료, 좋다, 맛, 보통, 최고, 멋있다}

이 X는 세 댓글 전체로 구성한 단어집합입니다. 이렇게 만든 단어집합은 음식점의 분위기나 맛을 파악하는 데 도움을 줍니다.

벡터란 무엇인가요?

어느 음료수 회사가 신제품 관련 설문조사를 했습니다. 고객 A, B, C, D의 평가 점수가 각각 3, 4, 4, 5점이었습니다. 이 점수를 순서쌍으로 (3, 4, 4, 5)라고 나타낼 수 있습니다.

벡터 (Vector)

여러 개의 수를 순서쌍의 형태로 표현한 것을 벡터라 하고, 기호로 a⃗ 와 같이 나타냅니다. 순서쌍을 이루는 수 하나하나를 그 벡터의 성분이라고 합니다.

a⃗ = ( 31번째 42번째 43번째 54번째 )
서로 같은 벡터

두 벡터 a⃗=(a₁,a₂,…,aₙ), b⃗=(b₁,b₂,…,bₙ)의 대응하는 성분끼리 서로 같을 때 (즉 a₁=b₁, a₂=b₂, …, aₙ=bₙ), 두 벡터는 서로 같다고 하며 a⃗=b⃗로 나타냅니다.

b⃗ = (1, 0, 0, 0, 1, 1, 1, 0)
c⃗ = (1, 0, 1, 0, 0, 0, 1, 1)
왜 이렇게 표현할까?

문장으로 이루어진 텍스트 데이터를 벡터로 표현하면 인공지능이 데이터를 인식할 수 있게 되고, 대량의 데이터를 빠른 속도로 처리할 수 있습니다. 이것이 텍스트 데이터를 수치화하는 가장 기본적인 방법입니다.

1회차 핵심 정리

오늘 배운 것

① 인공지능의 개념 — 인간의 지능을 모방하여 학습·추론·지각을 실현한 기술. 지도학습, 비지도학습, 강화학습으로 구분.

② 퍼셉트론 — 입력값×가중치의 합을 활성화함수의 임곗값과 비교해 출력값을 결정. 은닉층이 추가되면 딥러닝.

③ 빅데이터의 3V — 크기(Volume), 속도(Velocity), 다양성(Variety). 데이터 공정성이 중요.

④ 집합과 단어집합 — 텍스트를 단어 단위로 분리하고 불용어를 제거하여 집합으로 표현.

⑤ 벡터 — 단어집합을 기준으로 각 텍스트를 0/1로 이루어진 벡터로 변환.

다음 회차 예고

2회차에서는 0/1 벡터의 한계(빈도 정보 없음)를 보완하는 빈도수 벡터와 TF-IDF를 배우고, 벡터 사이의 거리를 재는 자카드·유클리드·코사인 유사도를 학습합니다.
