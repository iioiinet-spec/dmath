유클리드 거리와 유사도

두 점(또는 벡터) 사이의 직선 거리를 유클리드 거리라 하며, 이 거리를 이용하여 두 데이터의 유사도를 측정할 수 있습니다.

[그림] 유클리드 거리 시각화
점 A (벡터 A) 점 B (벡터 B) 유클리드 거리 d(A,B)
벡터 좌표 입력
A 벡터 A
A = ( , , )
B 벡터 B
B = ( , , )
💡 팁: 입력칸에 직접 숫자를 입력하거나, 프리셋 버튼을 클릭하여 벡터를 설정하세요. 캔버스 위의 점을 드래그하여 직접 이동시킬 수도 있습니다.
유클리드 거리 공식
2차원 공간
d(A,B) = √[(x₂−x₁)² + (y₂−y₁)²]
n차원 공간
d(A,B) = √[Σ(Aᵢ − Bᵢ)²]
유클리드 유사도 (Similarity)
similarity = 1 / (1 + d(A,B))
거리가 0이면 유사도는 1(완전 동일), 거리가 커질수록 유사도는 0에 가까워집니다.
계산 결과
유클리드 거리 d(A,B)
√[(6−3)² + (8−4)²]
5.000
유클리드 유사도
similarity = 1 / (1 + 5.000)
0.167
0 (완전 다름) 1 (완전 동일)
16.7%
계산 과정
① d² = (6 − 3)² + (8 − 4)²
② d² = 3² + 4² = 9 + 16 = 25
③ d = √25 = 5.000
④ similarity = 1/(1+5) = 0.167
벡터 정보
A 벡터 A의 크기 |A|
5.000
B 벡터 B의 크기 |B|
10.000
|A − B| (거리)
5.000
유클리드 유사도의 응용
🎬 영화 추천 시스템
사용자의 영화 평점 벡터와 유사한 평점 패턴을 가진 다른 사용자를 찾아 영화를 추천
🖼️ 이미지 유사도 검색
이미지의 픽셀값을 벡터로 변환하여 유사한 이미지를 검색
📊 K-Means 클러스터링
데이터 포인트 간의 거리를 기준으로 군집(클러스터)을 형성
🤖 K-NN 분류
가장 가까운 K개의 이웃 데이터를 찾아 새로운 데이터의 클래스를 예측
코사인 유사도와 비교
코사인 유사도 1.000
차이점: 유클리드 유사도는 거리를 기준으로 하고, 코사인 유사도는 방향(각도)을 기준으로 합니다. 같은 방향이면 코사인 유사도는 1이지만, 거리가 멀면 유클리드 유사도는 작아집니다.
