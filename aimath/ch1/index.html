지도학습 vs 비지도학습
수학으로 이해하고, 파이썬으로 실습하기

평균 · 오차 · 거리라는 수학 도구로 기계가 "학습"하는 원리를 파헤치고, 그대로 파이썬 코드로 옮깁니다.

인공지능 · 머신러닝 · 딥러닝 — 포함 관계부터

인공지능(AI)은 인간의 지적 능력을 기계로 구현하려는 가장 넓은 개념이고, 그 안에 데이터로부터 스스로 규칙을 찾는 머신러닝이, 다시 그 안에 인공신경망을 깊게 쌓은 딥러닝이 들어 있습니다.

빅데이터 — 머신러닝의 연료

머신러닝이 힘을 내려면 데이터가 필요합니다. 빅데이터의 특징은 3V로 요약됩니다.

Volume — 규모
엄청난 양
예하루에 쌓이는 검색 기록, 유튜브 영상
Velocity — 속도
실시간 생성 · 처리
예내비게이션 실시간 교통 정보
Variety — 다양성
숫자 + 텍스트 + 이미지 + …
예SNS의 글, 사진, 영상, 위치 정보
데이터의 수학적 표현
순서쌍 (x, y), 점 (x₁, x₂)
핵심데이터를 좌표평면의 점으로 보는 순간, 수학이 시작됩니다

기계는 어떻게 배울까? — 학습의 세 가지 방식

🧭
구분 기준은 단 하나 — "정답이 주어지는가?" 문제집에 답지가 있으면 지도학습, 답지 없이 스스로 유형을 묶어 보면 비지도학습입니다. 이 단원에서는 앞의 두 가지를 수학으로 파헤칩니다.

이 강의에서 쓰는 수학 도구 4가지

① 평균 — 데이터의 중심  ② 오차와 제곱 — 예측이 얼마나 틀렸나  ③ 일차함수 — 가장 단순한 예측 모델  ④ 두 점 사이의 거리 — "비슷하다"의 수학적 정의. 전부 이미 배운 내용입니다!

지도학습 — 정답으로부터 배운다

지도학습의 데이터는 (입력 xᵢ, 정답 yᵢ) 쌍입니다. 정답이 연속적인 수(점수, 가격)면 회귀, 범주(스팸/정상)면 분류라고 부릅니다. 여기서는 회귀의 대표인 선형회귀를 수학적으로 완전히 이해해 봅니다.

예제 데이터: 공부 시간(x)과 시험 점수(y) — 8명의 학생

x (시간)12345678
y (점수)5556626974778190

목표: 이 데이터를 가장 잘 설명하는 직선 ŷ = ax + b 를 찾아 9시간 공부한 학생의 점수를 예측하기

① 모델과 오차 — "얼마나 틀렸는가"를 수로 만들기

직선 ŷ = ax + b 가 하나 정해지면, 각 학생마다 오차(잔차) eᵢ = yᵢ − ŷᵢ = yᵢ − (axᵢ + b) 가 생깁니다. 직선 전체의 "틀린 정도"는 오차들을 제곱해 평균 낸 평균제곱오차(MSE)로 측정합니다.

E(a, b) = (1/n) Σ ( yᵢ − (axᵢ + b) )²
💡
왜 제곱할까? ① 오차의 부호(+/−)가 상쇄되는 것을 막고 ② 큰 오차에 훨씬 큰 벌점을 주며 ③ 그래프가 매끄러운 아래로 볼록 함수가 되어 최솟값이 딱 하나 존재하기 때문입니다. "학습"이란 이 E(a,b)를 최소로 만드는 a, b를 찾는 일입니다.

② 최소제곱법 — 최적의 a, b를 공식으로

E(a,b)를 최소화하는 해는 공식으로 딱 떨어집니다. x̄, ȳ는 각각 x, y의 평균입니다.

기울기 a — 편차곱의 합 ÷ 편차제곱의 합
a = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²
우리 데이터a = Sxy/Sxx = 210/42 = 5
절편 b — 직선은 평균점을 지난다
b = ȳ − a·x̄
우리 데이터b = 70.5 − 5 × 4.5 = 48

따라서 최적 직선은 ŷ = 5x + 48. 9시간 공부하면 5×9+48 = 93점으로 예측! 절편 공식은 회귀직선이 항상 평균점 (x̄, ȳ)를 지난다는 뜻이기도 합니다.

③ 작은 데이터로 손계산 연습

데이터 (1,3), (2,4), (3,6), (4,7) 의 회귀직선 구하기 — x̄ = 2.5, ȳ = 5

회귀 시뮬레이터 — 직접 직선을 움직여 오차를 줄여 보세요

슬라이더로 기울기 a와 절편 b를 조절하면 주황 점선(각 점의 오차)과 MSE가 실시간으로 변합니다. MSE를 얼마나 줄일 수 있나요? 다 줄였다면 「최소제곱 최적해」와 비교해 보세요.

ŷ = 2.0x + 60.0 MSE = ?

비지도학습 — 정답 없이 구조를 발견한다

이번에는 정답(레이블)이 없습니다. 데이터의 숨은 구조를 스스로 찾아야 합니다. 대표 문제가 비슷한 점끼리 묶는 군집화(clustering)이고, 그 대표 알고리즘이 k-평균(k-means)입니다. (특징을 압축하는 차원 축소도 비지도학습입니다.)

① "비슷하다"의 수학적 정의 — 두 점 사이의 거리

군집화의 출발점은 "가깝다 = 비슷하다"입니다. 좌표평면에서 두 점 사이의 거리는 피타고라스 정리 그 자체입니다.

유클리드 거리
d(P,Q) = √( (x₁−x₂)² + (y₁−y₂)² )
예제P(1,2), Q(4,6): d = √(3²+4²) = √25 = 5
중심(평균점) — 그룹의 대표 위치
c = ( x들의 평균, y들의 평균 )
예제(1,2),(3,4),(5,6)의 중심 = (3, 4)

② k-평균 알고리즘 — 딱 두 동작의 반복

군집의 개수 k를 정하면(여기서는 k = 2), 알고리즘은 할당과 갱신을 번갈아 반복할 뿐입니다.

0
초기화 — 중심 k개를 아무 곳에나 놓는다
우리 예제: 중심을 일부러 엉뚱한 위치 c₁(1, 2), c₂(6, 9)에 놓고 시작합니다.
1
할당 단계 — 각 점을 가장 가까운 중심의 그룹에
모든 점 p에 대해 d(p, c₁)과 d(p, c₂)를 계산해 더 가까운 쪽 그룹에 넣습니다.
p의 그룹 = argminₖ d(p, cₖ)
2
갱신 단계 — 각 중심을 자기 그룹의 평균점으로 이동
그룹이 바뀌었으니 대표 위치도 다시 계산합니다. 새 중심 = 그룹에 속한 점들의 평균.
cₖ = ( 그룹 점들의 x 평균, y 평균 )
3
반복 — 할당이 더 이상 바뀌지 않으면 수렴!
할당 → 갱신 → 할당 → … 을 반복하다가, 어떤 점도 그룹을 옮기지 않으면 끝납니다.
🎯
k-평균이 줄이려는 양(목적함수): 각 점에서 자기 중심까지 거리 제곱의 총합 ΣΣ‖p − cₖ‖². 할당 단계도, 갱신 단계도 이 값을 절대 늘리지 않기 때문에 알고리즘은 반드시 멈춥니다. 지도학습의 MSE처럼, 비지도학습도 결국 "오차 제곱합 최소화"라는 같은 수학 위에 서 있습니다!

파이썬 실습 ① — 최소제곱법을 직접 구현하기

1번 탭의 공식을 순수 파이썬으로 그대로 옮깁니다. 라이브러리 없이도 회귀는 열 줄이면 충분합니다.

Python regression.py — 공식을 코드로
# 데이터: 공부 시간(x) vs 시험 점수(y)
x = [1, 2, 3, 4, 5, 6, 7, 8]
y = [55, 56, 62, 69, 74, 77, 81, 90]
n = len(x)

mx = sum(x) / n                       # x의 평균 = 4.5
my = sum(y) / n                       # y의 평균 = 70.5

# 편차곱의 합 Sxy, 편차제곱의 합 Sxx
Sxy = sum((x[i]-mx) * (y[i]-my) for i in range(n))
Sxx = sum((x[i]-mx) ** 2 for i in range(n))

a = Sxy / Sxx                         # 기울기 공식
b = my - a * mx                       # 절편 공식
print("Sxy =", Sxy, ", Sxx =", Sxx)
print("회귀 직선: y =", a, "x +", b)
실행 결과Sxy = 210.0 , Sxx = 42.0 회귀 직선: y = 5.0 x + 48.0
Python predict.py — 예측과 모델 평가
# 학습된 모델(a, b)로 새 입력을 예측
print("9시간 공부 예측 점수:", a*9 + b)

# 모델이 얼마나 좋은지: MSE (작을수록 좋다)
mse = sum((y[i] - (a*x[i] + b))**2 for i in range(n)) / n
print("MSE =", mse)
실행 결과9시간 공부 예측 점수: 93.0 MSE = 2.5
Python bonus.py — numpy로는 한 줄
import numpy as np

a, b = np.polyfit(x, y, 1)   # 1차(직선) 다항식 피팅
print("기울기:", round(a, 6), " 절편:", round(b, 6))
실행 결과기울기: 5.0 절편: 48.0
✅
손계산 = 코드 = 라이브러리, 세 결과가 완전히 일치! 공식(a = 210/42 = 5)과 직접 구현, np.polyfit이 모두 같은 답을 냅니다. 라이브러리는 마법이 아니라 우리가 아는 수학을 대신 계산해 주는 것뿐임을 보여주는 순간입니다.

파이썬 실습 ② — k-평균을 직접 구현하기

2번 탭 시뮬레이터와 완전히 같은 데이터, 같은 초기 중심으로 k-평균을 구현합니다. 시뮬레이터에서 눈으로 본 중심의 이동 경로가 코드 출력에 그대로 나타나는지 비교해 보세요.

Python kmeans.py — 할당과 갱신의 반복
import math

points = [(1, 6), (2, 8), (2.5, 7), (1.5, 7.5), (3, 6.5), (2, 6),
          (6, 2), (7, 3.5), (8, 2.5), (7.5, 4), (6.5, 3), (8, 3.5)]
centroids = [(1, 2), (6, 9)]      # 초기 중심 (일부러 엉뚱한 곳에!)

def dist(p, q):                    # 유클리드 거리 = 피타고라스
    return math.sqrt((p[0]-q[0])**2 + (p[1]-q[1])**2)

prev = None
for step in range(1, 11):
    # ① 할당: 각 점을 더 가까운 중심의 그룹(0 또는 1)으로
    assign = [0 if dist(p, centroids[0]) < dist(p, centroids[1]) else 1
              for p in points]
    if assign == prev:             # 할당이 안 바뀌면 수렴
        print(step, "번째 할당에서 변화 없음 → 수렴!")
        break
    # ② 갱신: 각 그룹의 평균점으로 중심 이동
    groups = [[], []]
    for p, k in zip(points, assign):
        groups[k].append(p)
    centroids = [(sum(p[0] for p in g)/len(g), sum(p[1] for p in g)/len(g))
                 for g in groups]
    print(step, "회 갱신 후 중심:",
          [(round(cx, 2), round(cy, 2)) for cx, cy in centroids])
    prev = assign

print("최종 중심:", [(round(cx, 2), round(cy, 2)) for cx, cy in centroids])
실행 결과1 회 갱신 후 중심: [(3.88, 4.25), (4.94, 5.31)] 2 회 갱신 후 중심: [(2.62, 5.38), (5.56, 4.75)] 3 회 갱신 후 중심: [(2.0, 6.83), (7.17, 3.08)] 4 번째 할당에서 변화 없음 → 수렴! 최종 중심: [(2.0, 6.83), (7.17, 3.08)]
✅
시뮬레이터와 코드가 완전히 같은 경로로 움직입니다. 3회 갱신 만에 중심이 (2, 6.83)과 (7.17, 3.08) — 왼쪽 위 그룹과 오른쪽 아래 그룹의 한가운데 — 로 수렴합니다. 눈으로 본 것과 코드가 일치할 때 알고리즘은 완전히 이해된 것입니다.
⚠️
k-평균의 두 가지 주의점. ① k(군집 개수)는 사람이 미리 정해야 합니다. ② 초기 중심 위치에 따라 다른 결과로 수렴할 수 있습니다(지역 최적해). 그래서 실무에서는 초기값을 바꿔 여러 번 실행합니다.

정답(점수)이 있으니 지도학습이고, 점수는 연속적인 수이므로 회귀입니다. 스팸/정상처럼 범주를 맞히면 분류입니다.
3평균제곱오차(MSE)의 올바른 식은?
오차를 제곱해 평균 냅니다. 제곱이 없으면(1번 보기) 양수·음수 오차가 상쇄되어 엉망인 직선도 오차 0처럼 보일 수 있습니다.
4최소제곱법에서 기울기 a를 구하는 공식은?
a = 편차곱의 합 ÷ x 편차제곱의 합 = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)². 절편은 b = ȳ − a·x̄로 뒤따라 나옵니다.
5데이터 (1,3),(2,4),(3,6),(4,7)의 회귀직선 기울기는? (Sxy=7, Sxx=5)
a = Sxy/Sxx = 7/5 = 1.4. 절편은 b = 5 − 1.4×2.5 = 1.5, 회귀직선은 ŷ = 1.4x + 1.5.
6두 점 P(1, 2), Q(4, 6) 사이의 유클리드 거리는?
d = √((4−1)² + (6−2)²) = √(9+16) = √25 = 5. 3-4-5 직각삼각형, 피타고라스 정리입니다.
7k-평균의 갱신 단계에서 각 중심은 어디로 이동하는가?
새 중심 = (그룹 점들의 x 평균, y 평균). 평균점이 그룹까지의 거리 제곱합을 최소로 만드는 위치이기 때문입니다.
8"쇼핑몰 고객을 비슷한 구매 패턴끼리 묶기"는 어떤 문제인가?
"어떤 그룹이 몇 개 있는지" 정답이 미리 없으므로 비지도학습의 군집화입니다. 만약 '우수/일반 고객' 정답표가 이미 있다면 분류가 됩니다.
