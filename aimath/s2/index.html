Ⅱ-2 · 텍스트 데이터의 정보 추출 (1)

텍스트 데이터를 어떻게 요약하나요?

앞에서 텍스트의 문장들을 성분이 0 또는 1인 벡터로 나타내어 보았는데, 이 방법으로는 주어진 데이터에서 특정 단어가 얼마나 자주 출현하는지는 알 수 없습니다. 하지만 단어들이 출현하는 빈도수를 벡터로 나타내면, 그 단어가 얼마나 자주 사용되었는지 알 수 있고 텍스트의 주제어도 찾을 수 있습니다.

예시 상황

한 애견용품점의 구매 후기 3개로 텍스트 데이터를 요약하고 주제어를 찾는 방법을 알아봅시다.

후기내용
A애견재킷 추천합니다. 디자인이 예쁘고 가격이 저렴해서 추천해요.
B애견재킷 추천! 애견재킷 사이즈도 다양해요!
C예쁜 애견재킷 추천! 디자인이 예뻐요.

불용어를 제거한 단어집합은 각각 다음과 같습니다.

A = {애견재킷, 추천, 디자인, 예쁘다, 가격, 저렴하다}
B = {애견재킷, 추천, 사이즈, 다양하다}
C = {예쁘다, 애견재킷, 추천, 디자인}
Ⅱ-2 · 텍스트 데이터의 정보 추출 (2)

단어가방(Bag of Words)과 빈도수 벡터

단어가방 (Bag of Words)

텍스트 데이터에 출현하는 단어들을 모두 분해하여 하나의 가방에 넣은 것. 단어가방 안에서 각 단어의 중복 횟수를 세면, 전체 텍스트에서 그 단어가 몇 번 나왔는지(출현 빈도수)를 알 수 있습니다.

출현 빈도수 표

애견재킷추천디자인예쁘다가격저렴하다사이즈다양하다
후기 A12111100
후기 B21000011
후기 C11120000
전체 후기44231111

위 표를 빈도수 벡터로 나타내면:

a⃗ = (1, 2, 1, 1, 1, 1, 0, 0)
b⃗ = (2, 1, 0, 0, 0, 0, 1, 1)
c⃗ = (1, 1, 1, 2, 0, 0, 0, 0)
x⃗ = (4, 4, 2, 3, 1, 1, 1, 1) (전체 후기)
주제어 찾기

출현 빈도수가 가장 높은 단어를 주제어라고 할 수 있습니다. 후기 A의 주제어는 '추천'(2회), 후기 B의 주제어는 '애견재킷'(2회), 후기 C의 주제어는 '예쁘다'(2회)입니다. 전체 후기에서는 '애견재킷'과 '추천'이 공동 주제어(4회)입니다.

TF-IDF: 정말 중요한 단어 찾기

왜 빈도수만으로는 부족할까?

여러 문서에 공통으로 자주 등장하는 단어(예: '그리고', '그것')는 출현 빈도수는 높지만 그 문서만의 중요한 단어는 아닙니다. 어떤 단어가 특정 문서 내에서만 두드러지게 중요한지 알아내려면 다른 지표가 필요합니다. 그것이 TF-IDF입니다.

단어빈도 (TF, Term Frequency)

각 문서에서 특정 단어가 출현하는 횟수. 한 문서 안에서 그 단어가 얼마나 자주 쓰였는지를 나타냅니다.

문서빈도 (DF, Document Frequency)

특정 단어가 출현하는 문서의 개수. 예를 들어 전체 10개 문서 중 7개 문서에 '인공지능'이 등장하면 DF=7입니다.

역문서빈도 (IDF) & TF-IDF

전체 문서 수를 k라고 할 때,

IDF = k / DF

그리고 최종 지표는

TF-IDF = TF × IDF
핵심 포인트

어떤 단어가 한 문서에서는 자주 나오지만(TF가 큼), 전체 문서 중에서는 적은 수의 문서에만 등장한다면(DF가 작아서 IDF가 큼) → TF-IDF 값이 커집니다. 즉, TF-IDF가 클수록 그 단어는 해당 문서 내에서 특히 중요한 단어라는 뜻입니다.

자카드 유사도

이제 두 텍스트 데이터가 얼마나 비슷한지를 수치로 나타내는 유사도를 배워봅니다. 가장 먼저 배울 것은 집합을 이용한 자카드 유사도입니다.

자카드 유사도 (Jaccard Similarity)

두 텍스트 데이터 A와 B의 단어집합이 A, B일 때,

J(A, B) = n(A∩B) / n(A∪B)

즉, 공통으로 등장하는 단어의 수를 전체 등장하는 단어 수로 나눈 값입니다.

값의 의미

자카드 유사도의 값이 1에 가까울수록 두 텍스트는 더 유사합니다. (값의 범위: 0 ~ 1)

예를 들어 A = {분위기, 신선하다, 재료, 좋다}, B = {애견재킷, 추천, 사이즈, 다양하다}라면 공통 원소가 없으므로 A∩B = ∅이고, J(A,B) = 0/8 = 0 입니다. 즉 두 텍스트는 전혀 유사하지 않습니다.

J(A, B) =

유클리드 유사도

좌표평면 위의 두 점 사이의 거리 공식을 기억하시나요? 이 개념을 벡터로 확장하면 두 텍스트(벡터)가 공간에서 얼마나 가까운지 알 수 있습니다.

복습: 두 점 사이의 거리

좌표평면 위의 두 점 (x₁, y₁), (x₂, y₂) 사이의 거리는 √[(x₁-x₂)² + (y₁-y₂)²] 입니다.

유클리드 유사도 (Euclidean Similarity)

두 텍스트 데이터 A와 B를 나타내는 벡터가 각각 a⃗=(a₁,a₂,…,aₙ), b⃗=(b₁,b₂,…,bₙ)일 때, 유클리드 유사도는 다음과 같습니다.

√[(a₁-b₁)² + (a₂-b₂)² + ⋯ + (aₙ-bₙ)²]

이것은 두 벡터의 종점 사이의 거리입니다.

값의 의미 (주의!)

유클리드 유사도의 값이 0에 가까울수록 더 유사합니다. 자카드/코사인 유사도와는 반대 방향으로 해석한다는 점에 유의하세요 — 이건 사실 '거리'이기 때문에, 거리가 가까울수록(값이 작을수록) 유사한 것입니다.

Q두 벡터 a⃗=(1, 2, 3), b⃗=(4, 2, 1)의 유클리드 유사도(거리)를 구하시오.
값 =
(1-4)² + (2-2)² + (3-1)² 을 먼저 계산한 다음 √ 를 씌우세요.
Ⅱ-3 · 텍스트 데이터의 분석 (3)

코사인 유사도

벡터의 방향이 얼마나 비슷한지를 측정하는 방법입니다. 텍스트 데이터 분석에서 가장 널리 쓰이는 유사도 지표 중 하나입니다.

코사인 유사도 (Cosine Similarity)

두 벡터 a⃗=(a₁,…,aₙ), b⃗=(b₁,…,bₙ)일 때,

(a₁b₁ + a₂b₂ + ⋯ + aₙbₙ) / [√(a₁²+⋯+aₙ²) × √(b₁²+⋯+bₙ²)]
값의 의미

코사인 유사도의 값이 1에 가까울수록 더 유사합니다. (자카드 유사도와 같은 해석 방향)

예제: 단어 임베딩과 코사인 유사도

단어를 벡터로 표현(단어 임베딩)했을 때, 비슷한 의미를 가진 단어는 벡터의 방향이 비슷합니다.

단어고양이물고기강아지귀엽다
벡터(1, 0, 2)(1, 1, 2)(0, 2, 1)(0, 0, 1)

'귀엽다'와 가장 유사한 단어를 찾아봅시다. '귀엽다'=(0,0,1)과 '고양이'=(1,0,2)의 코사인 유사도는:

(0×1 + 0×0 + 1×2) / (√1 × √5) = 2/√5 ≈ 0.894

같은 방식으로 계산하면 '귀엽다'-'물고기'≈0.816, '귀엽다'-'강아지'≈0.447입니다. 따라서 2/√5 > 2/√6 > 1/√5 이므로 '귀엽다'와 가장 유사한 단어는 '고양이'입니다.

오늘 배운 것

① 빈도수 벡터 — 단어의 출현 횟수를 벡터로 표현하면 주제어를 찾을 수 있다.

② 단어가방(Bag of Words) — 텍스트에 등장하는 모든 단어를 모아 빈도수를 계산하는 방법.

③ TF-IDF — 단어빈도(TF) × 역문서빈도(IDF)로, 한 문서에서 특히 중요한 단어를 찾는 지표.

④ 자카드 유사도 — n(A∩B)/n(A∪B), 1에 가까울수록 유사.

⑤ 유클리드 유사도 — 벡터 사이의 거리, 0에 가까울수록 유사 (반대 해석 주의!).

⑥ 코사인 유사도 — 벡터의 방향 일치도, 1에 가까울수록 유사. 텍스트 분석에서 가장 많이 사용.
