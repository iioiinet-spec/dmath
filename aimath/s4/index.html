해밍 거리로 이미지 비교하기

Ⅲ-3 · 이미지 데이터의 분류 (3)

데이터 속성을 이용한 분류 방법

인공지능이 개와 고양이를 분류한다고 합시다. 코의 크기, 귀의 모양 등 이미지의 특징을 추출한 후, 이 속성들을 좌표 위에 표시하여 분류 기준을 만듭니다.

k최근접 이웃 (KNN, k-Nearest Neighbor)

새로운 데이터가 입력되면, 가까이 있는 k개의 이웃 데이터를 살펴본 후 가장 많이 나온 값(범주)으로 분류하는 방법입니다. 점과 점 사이의 거리를 계산하는 수학적 원리가 활용됩니다.

예시

새로운 데이터의 가장 가까운 k=3개의 이웃을 살펴봤더니 강아지 데이터 1개, 고양이 데이터 2개였다면, 고양이가 더 많으므로 이 데이터는 고양이로 분류됩니다.

서포트 벡터 머신 분류 (경계선 분류)

학습한 데이터의 특성을 통해 영역을 분류할 수 있는 최적의 경계선을 찾는 방법입니다. 이 경계선을 찾는 과정에서 점과 직선 사이의 거리 공식이 활용됩니다. 새로운 데이터가 입력되면 경계선을 기준으로 어느 영역에 속하는지로 분류합니다.

Qk최근접 이웃(KNN) 분류에서 k=5일 때 가까운 이웃 중 강아지 3개, 고양이 2개가 나왔다면 어떻게 분류되나요?
Ⅳ-1 · 확률과 예측

인공지능에서 확률은 어디에 사용되나요?

일기 예보를 할 때는 기상 관련 엄청난 양의 데이터를 수집하고 분석하여 비가 올 확률이나 기온을 예측합니다. 예를 들어 오늘과 비슷한 기상 조건을 가진 날이 100일 있었을 때, 그중 80일이 비가 왔다면 비가 올 확률은 상대도수를 이용하여 구할 수 있습니다.

상대도수를 이용한 확률
확률 = 사건이 일어난 횟수 / 전체 시행 횟수

예) 100일 중 80일 비가 왔다면, 확률 = 80/100 = 0.8 (80%)

Ⅳ-2 · 추세선과 예측 (2)

상관관계의 종류

산점도에 나타난 점들의 분포 형태로, 두 변량 사이의 관계(상관관계)를 파악할 수 있습니다.

📈
양의 상관관계
한 변량이 증가할 때 다른 변량도 증가하는 경향. (예: 키와 몸무게)
📉
음의 상관관계
한 변량이 증가할 때 다른 변량은 감소하는 경향. (예: 가격과 판매량)
⚪
상관관계 없음
두 변량 사이에 뚜렷한 증가·감소 경향이 보이지 않음.

4회차 핵심 정리

오늘 배운 것

① 해밍 거리 — 같은 위치의 다른 성분 개수. 작을수록 두 이미지(행렬)가 더 유사하다.

② MNIST와 분류 — 손글씨 숫자 데이터셋. 해밍 거리로 새 이미지를 가장 가까운 숫자로 분류한다.

③ KNN과 경계선 분류 — 가까운 이웃의 다수결, 또는 영역을 나누는 경계선으로 분류한다.

④ 확률과 예측 — 확률 = 사건이 일어난 횟수 ÷ 전체 시행 횟수 (상대도수).

⑤ 산점도와 상관관계 — 두 변량의 관계를 점으로 표현하고, 양/음/없음의 상관관계로 해석한다.

⑥ 추세선 — 데이터의 경향성을 나타내는 직선으로, 미래의 값을 예측하는 데 사용한다.
