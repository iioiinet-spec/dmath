💻 Python 실행 코드 (Scikit-learn)

현재 설정된 문장이 적용된 파이썬 코드입니다. 오른쪽 상단 버튼으로 복사할 수 있습니다.

from sklearn.feature_extraction.text import TfidfVectorizer from sklearn.metrics.pairwise import cosine_similarity # 1. 입력 문장 정의 sentences = [ "오늘 날씨는 매우 화창하고 기분이 좋습니다", "오늘 날씨가 정말 화창해서 기분이 좋습니다" ] # 2. TfidfVectorizer 객체 생성 및 학습 vectorizer = TfidfVectorizer() tfidf_matrix = vectorizer.fit_transform(sentences) # 3. 추출된 단어 목록 및 TF-IDF 행렬 확인 feature_names = vectorizer.get_feature_names_out() matrix_array = tfidf_matrix.toarray() # 4. 코사인 유사도 계산 sim_matrix = cosine_similarity(tfidf_matrix[0:1], tfidf_matrix[1:2]) similarity_score = sim_matrix[0][0] print(f"코사인 유사도: {similarity_score:.4f}")
