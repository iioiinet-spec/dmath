Ⅳ-3 · 손실함수 (2)

손실함수란 무엇인가요?

n개의 데이터 (x₁,y₁), (x₂,y₂), …, (xₙ,yₙ)으로부터 f(x)=ax 꼴의 추세선을 결정했을 때, 오차는 y₁-ax₁, y₂-ax₂, …, yₙ-axₙ 입니다.

손실함수 E(a)

오차의 제곱의 평균을 그 데이터의 추세선에 대한 손실함수라 하고, 다음과 같이 계산합니다.

E(a) = (1/n) × {(y₁-ax₁)² + (y₂-ax₂)² + ⋯ + (yₙ-axₙ)²}

손실함수 기호 E는 오차를 의미하는 'Error'의 첫 글자입니다.

중요한 사실

E(a)의 우변을 정리하면 a에 대한 이차식이 됩니다. 즉, 손실함수 E(a)는 추세선 f(x)=ax의 기울기 a에 대한 이차함수입니다. 이는 다음 페이지에서 완전제곱식으로 최솟값을 구할 수 있다는 중요한 의미를 가집니다.

손실함수의 최적화

손실함수의 최적화

손실함수 E(a)의 함숫값이 최소가 되는 추세선 y=ax의 기울기 a를 찾는 과정을 손실함수의 최적화라 하고, 이때의 추세선을 최적화된 추세선이라고 합니다.

완전제곱식으로 최솟값 구하기

데이터 (0,1), (1,1), (1,2), (2,3)에 대하여 추세선 f(x)=ax의 손실함수를 구하면:

E(a) = ¼{1² + (1-a)² + (2-a)² + (3-2a)²}

이를 완전제곱식으로 정리하면:

E(a) = (3/2){a - 3/2}² + 3/8
최솟값 찾기

완전제곱식 E(a) = (3/2)(a - 3/2)² + 3/8 에서, (a-3/2)² ≥ 0 이므로 a = 3/2일 때 E(a)의 최솟값은 3/8입니다. 따라서 최적화된 추세선은 f(x) = (3/2)x 입니다.

Ⅳ-4 · 미분 (1)

함수의 극한은 무엇일까요?

왜 극한이 필요할까?

손실함수가 이차함수일 때는 완전제곱식으로 최솟값을 구할 수 있었습니다. 하지만 손실함수가 더 복잡한 경우에는 일반화된 방법이 필요한데, 이때 함수의 극한과 미분이 활용됩니다.

함수 f(x)=x-1에서 x의 값이 2에 가까워질 때, f(x)의 값은 어떻게 변하는지 살펴봅시다.

x1.91.991.999→ 2 →2.0012.012.1
f(x)0.90.990.999→ 1 →1.0011.011.1
함수의 수렴과 극한값

함수 y=f(x)에서 x의 값이 a가 아니면서 a에 한없이 가까워질 때, f(x)의 값이 일정한 값 L에 한없이 가까워지면 함수 f(x)는 L에 수렴한다고 합니다. 이때 L을 함수 f(x)의 극한값이라 하며, 기호로 다음과 같이 나타냅니다.

lim(x→a) f(x) = L

위 표에서 x의 값이 2에 가까워질 때 f(x)의 값은 1에 가까워지므로,

lim(x→2) (x-1) = 1

Ⅳ-4 · 미분 (2)

접선의 기울기와 미분계수

함수 y=f(x)의 그래프 위의 두 점 P(a, f(a)), Q(a+h, f(a+h))를 지나는 직선 PQ의 기울기는 x의 값이 a에서 a+h까지 변할 때의 평균변화율입니다.

{f(a+h) - f(a)} / h
h가 0에 가까워지면?

h→0이면 점 Q는 곡선 y=f(x)를 따라 점 P에 한없이 가까워지고, 직선 PQ는 점 P를 지나는 접선에 한없이 가까워집니다. 이 접선의 기울기를 미분계수라고 합니다.

미분계수 f'(a)

함수 y=f(x)의 x=a에서의 미분계수는 다음과 같습니다.

f'(a) = lim(h→0) {f(a+h) - f(a)} / h

예시: 미분계수 계산

함수 f(x)=x²+4x-3의 x=1에서의 미분계수를 구해봅시다.

f'(1) = lim(h→0) [{(1+h)²+4(1+h)-3} - (1²+4×1-3)] / h
= lim(h→0) (h²+6h)/h = lim(h→0) (h+6) = 6

즉, 점 (1, 2)에서의 접선의 기울기는 6입니다.

Q함수 f(x)=x²+2x의 x=2에서의 미분계수 f'(2)를 구하시오. (힌트: f'(2) = lim(h→0)[{(2+h)²+2(2+h)} - (2²+2×2)]/h )
f'(2) =
{(2+h)²+2(2+h)} = 4+4h+h²+4+2h = h²+6h+8 이고, (2²+2×2)=8 이므로 분자는 h²+6h가 됩니다.
Ⅳ-4 · 미분 (3)

이차함수의 미분계수와 도함수

이차함수 f(x)=px²+qx+r의 x=t에서의 미분계수 f'(t)를 일반적으로 구해봅시다.

f'(t) = lim(h→0) {p(t+h)²+q(t+h)+r - (pt²+qt+r)} / h

이를 전개하고 정리하면:

f'(t) = 2pt + q
도함수란?

각 점에서의 미분계수를 일반적인 식으로 나타낸 함수 f'(x)를 도함수라고 합니다. f(x)=px²+qx+r의 도함수는 f'(x) = 2px + q 입니다. 이는 t자리에 x를 넣은 것과 같습니다.

손실함수에 적용하기

손실함수 E(a) = (3/2)a² - (9/2)a + 3 의 도함수 E'(a)를 구하면:

E'(a) = 2×(3/2)×a - 9/2 = 3a - 9/2

E'(a)=0이 되는 a의 값을 찾으면, 바로 손실함수가 최소가 되는 지점을 찾을 수 있습니다! 이것이 다음 회차에서 배울 경사하강법의 핵심 원리입니다.

오늘 배운 것

① 오차의 제곱의 평균(MSE) — 여러 추세선의 정확도를 비교하는 기준. 값이 작을수록 좋은 추세선.

② 손실함수 E(a) — 추세선 f(x)=ax의 기울기 a에 대한 이차함수로, 오차의 제곱의 평균을 나타낸다.

③ 손실함수의 최적화 — 완전제곱식을 이용해 E(a)의 최솟값과 그때의 a(최적화된 추세선)를 구한다.

④ 함수의 극한 — x가 a에 가까워질 때 f(x)가 가까워지는 값. lim(x→a)f(x)=L

⑤ 미분계수 — 접선의 기울기. f'(a)=lim(h→0){f(a+h)-f(a)}/h

⑥ 도함수 — 이차함수 f(x)=px²+qx+r의 도함수는 f'(x)=2px+q. E'(a)=0인 지점에서 최솟값을 가진다.
