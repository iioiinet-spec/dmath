최대공약수(GCD) & 최소공배수(LCM)

두 수의 공약수 중 가장 큰 것이 GCD, 공배수 중 가장 작은 것이 LCM입니다.

핵심 공식

GCD와 LCM의 관계:

GCD(a, b) × LCM(a, b) = a × b

즉, LCM을 구하려면:

LCM(a, b) = a × b / GCD(a, b)

유클리드 호제법

GCD를 효율적으로 구하는 핵심 알고리즘:

GCD(a, b) = GCD(b, a % b)
단, GCD(a, 0) = a

시간복잡도: O(log min(a,b))

C 언어 구현

// 재귀 방식
int gcd(int a, int b) {
return b == 0 ? a : gcd(b, a % b);
}

// 반복 방식
int gcd_iter(int a, int b) {
while (b) { int t = b; b = a % b; a = t; }
return a;
}

int lcm(int a, int b) { return a / gcd(a, b) * b; }

소수(Prime Number)

1과 자기 자신만을 약수로 가지는 자연수입니다. 2는 유일한 짝수 소수입니다.

소수 판별법

n의 약수는 반드시 √n 이하의 약수와 쌍을 이루므로, √n까지만 검사합니다.

bool isPrime(int n) {
if (n < 2) return false;
for (int i = 2; i*i <= n; i++)
if (n % i == 0) return false;
return true;
}

시간복잡도: O(√n)

에라토스테네스의 체

1~N 범위의 모든 소수를 한 번에 구할 때 사용합니다.

bool sieve[MAX] = {true};
sieve[0] = sieve[1] = false;
for (int i = 2; i*i <= N; i++)
if (sieve[i])
for (int j = i*i; j<=N; j+=i)
sieve[j] = false;

시간복잡도: O(N log log N)

에라토스테네스의 체 시뮬레이터 (2~60)

진법 변환

컴퓨터는 2진수(이진법)로 동작하며, 16진수는 이진수를 간결하게 표현할 때 사용합니다.

진법 개요

2진법 0, 1

8진법 0~7

10진법 0~9

16진법 0~9, A~F

16진수: A=10, B=11, C=12, D=13, E=14, F=15

변환 규칙

10진수 → N진수: 반복해서 N으로 나누고, 나머지를 역순으로 읽기

N진수 → 10진수: 각 자리수 × 자릿값(N의 거듭제곱) 합산

2진수 ↔ 16진수: 4비트씩 묶어서 변환 (가장 빠름)

1010 1111₂ = AF₁₆
A=1010, F=1111

2의 보수 (음수 표현)

컴퓨터에서 음수를 표현하는 방식입니다.

-n = ~n + 1 (비트 반전 후 1 더하기)

예) 8비트에서 -5:
5 = 0000 0101
~5 = 1111 1010 (비트 반전)
-5 = 1111 1011 (+1)

나머지 연산 (Modular Arithmetic)

큰 수의 계산에서 오버플로우를 방지하고, 주기성을 활용하는 핵심 기법입니다.

기본 성질

(a + b) % m = ((a%m) + (b%m)) % m
(a × b) % m = ((a%m) × (b%m)) % m
(a - b) % m = ((a%m) - (b%m) + m) % m

뺄셈에서 m을 더하는 이유: 음수 방지

거듭제곱의 나머지

분할정복을 활용한 빠른 거듭제곱:

long long power(long long a, long long b, long long m) {
long long res = 1; a %= m;
while (b > 0) {
if (b & 1) res = res * a % m;
a = a * a % m;
b >>= 1;
}
return res;
}

시간복잡도: O(log b)
