부분집합 전체 출력
N개의 원소가 있을 때, 가능한 모든 부분집합(공집합 포함)을 빠짐없이 출력하는 가장 기본적인 비트마스크 패턴입니다.

문제 부분집합 전체 출력

정수 N과 N개의 원소가 담긴 배열 arr가 주어진다. arr의 모든 부분집합(공집합 포함, 원소 순서 유지)을 한 줄에 하나씩 출력하라. 공집합은 { }로 출력한다.
입력 예시
N = 3
arr = [1, 2, 3]
출력 예시
{ }
{ 1 }
{ 2 }
{ 1 2 }
{ 3 }
{ 1 3 }
{ 2 3 }
{ 1 2 3 }
📌 제약조건: 1 ≤ N ≤ 20 (2^20 = 약 100만 개 부분집합까지 가능)
먼저 직접 풀어본 뒤 확인해보세요!
EXAMPLE 2 · ★★☆☆☆
집합 연산 (합집합·교집합·차집합)
두 집합을 비트마스크로 표현하면 합집합·교집합·차집합·대칭차집합을 모두 O(1)에 계산할 수 있습니다.

문제 두 집합의 연산 결과 출력

1번부터 N번까지의 원소 중 일부로 이루어진 두 집합 A, B가 비트마스크 정수로 주어진다(i번째 비트가 1이면 원소 i+1이 집합에 포함). 합집합, 교집합, A에서 B를 뺀 차집합, 대칭차집합을 각각 원소 목록으로 출력하라.
입력 예시
N = 5
A = 0b01011  (원소 1,2,4)
B = 0b01110  (원소 2,3,4)
출력 예시
합집합:    1 2 3 4
교집합:    2 4
차집합(A-B): 1
대칭차집합: 1 3
📌 제약조건: 1 ≤ N ≤ 30 (int 범위 내에서 충분)
먼저 직접 풀어본 뒤 확인해보세요!
EXAMPLE 3 · ★★★★☆
외판원 순회 (TSP, 비트마스크 DP)
N개의 도시를 모두 한 번씩 방문하고 출발점으로 돌아오는 최소 비용 경로를 구하는 대표적인 비트마스크 DP 문제입니다.

문제 외판원 순회 (TSP)

N개의 도시와 도시 간 이동 비용이 담긴 N×N 비용 행렬 cost[i][j]가 주어진다(이동 불가능하면 0으로 표시). 0번 도시에서 출발해 모든 도시를 정확히 한 번씩 방문한 뒤 다시 0번 도시로 돌아오는 최소 비용을 구하라.
입력 예시
N = 4
cost = 
[0,10,15,20]
[5, 0, 9,10]
[6,13, 0,12]
[8, 8, 9, 0]
출력 예시
35
(0→1→3→2→0
 = 10+10+9+6 = 35)
📌 제약조건: 2 ≤ N ≤ 16 (2^16 × 16 ≈ 100만, 1초 내 처리 가능)
먼저 직접 풀어본 뒤 확인해보세요!
EXAMPLE 4 · ★★★★☆
전구 스위치 최소 횟수 (BFS + 비트마스크)
N개의 전구가 일렬로 있고, 각 스위치를 누르면 특정 전구들이 토글됩니다. 모든 전구를 켜는 최소 스위치 조작 횟수를 비트마스크 BFS로 구합니다.

문제 전구 모두 켜기

N개의 전구가 있고(0=꺼짐, 1=켜짐), 초기 상태가 비트마스크로 주어진다. M개의 스위치가 있고, 각 스위치 i를 누르면 정해진 전구 집합(비트마스크 sw[i])이 토글(XOR)된다. 모든 전구를 켜는 데 필요한 최소 스위치 조작 횟수를 구하라. 불가능하면 -1을 출력한다.
입력 예시
N = 4 (전구 4개)
초기상태 = 0b0000
M = 3 (스위치 3개)
sw[0] = 0b0011 (전구 0,1 토글)
sw[1] = 0b0110 (전구 1,2 토글)
sw[2] = 0b1100 (전구 2,3 토글)
출력 예시
2
(sw[0]+sw[2] 누르면
 0b0011 XOR 0b1100
 = 0b1111 → 모두 켜짐)
📌 제약조건: 1 ≤ N ≤ 18, 1 ≤ M ≤ 18 (상태공간 2^N을 BFS로 탐색)
먼저 직접 풀어본 뒤 확인해보세요!
EXAMPLE 5 · ★★★★★
N-Queen 비트마스크 백트래킹
N×N 체스판에 퀸 N개를 서로 공격하지 않게 배치하는 경우의 수를 구합니다. 열과 두 대각선의 점유 상태를 비트마스크 3개로 관리하면 매우 빠르게 풀 수 있습니다.

문제 N-Queen 경우의 수

정수 N이 주어질 때, N×N 체스판에 퀸 N개를 서로 공격하지 못하도록 배치하는 방법의 총 개수를 구하라. (한 행에 정확히 하나씩 배치한다고 가정)
입력 예시
N = 8
출력 예시
92
📌 제약조건: 1 ≤ N ≤ 15 (비트마스크 가지치기 없이는 N=8도 매우 느려질 수 있음)
먼저 직접 풀어본 뒤 확인해보세요!
