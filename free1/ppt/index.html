수의 체계

수는 왜 체계가 필요할까?

수학에서는 숫자를 아무렇게나 다루지 않고, 성질에 따라 묶어서 생각합니다. 그래야 연산 규칙을 정확하게 세울 수 있습니다.

예시

3은 자연수이지만, -3은 자연수가 아닙니다. 1/2은 정수는 아니지만 유리수입니다.

자연수 ⊂ 정수 ⊂ 유리수 ⊂ 실수

수의 체계

자연수

자연수는 물건의 개수를 셀 때 사용하는 수입니다.

자연수 예

1, 2, 3, 4, 5, ...

주의

0을 자연수에 포함하는지 여부는 교재나 분야에 따라 다를 수 있습니다. 컴퓨터 과학에서는 0부터 세는 경우가 많습니다.

정수

정수는 자연수, 0, 음의 정수를 모두 포함합니다.

..., -3, -2, -1, 0, 1, 2, 3, ...

컴퓨터에서는 음수를 표현하기 위해 부호 비트나 2의 보수를 사용합니다. 뒤에서 다시 자세히 배웁니다.

수의 체계

유리수

유리수는 두 정수의 비율로 나타낼 수 있는 수입니다.

유리수 = a / b    (a, b는 정수, b ≠ 0)

예

1/2, -3/4, 0.25, 2

특징

소수로 나타내면 끝나는 소수 또는 반복되는 소수가 됩니다.

무리수 예

연산의 우선순위

  1. 괄호 안을 먼저 계산한다.
  2. 곱셈과 나눗셈을 먼저 계산한다.
  3. 덧셈과 뺄셈을 나중에 계산한다.
  4. 같은 우선순위는 왼쪽에서 오른쪽으로 계산한다.
3 + 4 × 2 = 11

교환법칙

덧셈과 곱셈은 순서를 바꾸어도 결과가 같습니다.

a + b = b + a
a × b = b × a

뺄셈과 나눗셈은 일반적으로 교환법칙이 성립하지 않습니다.

결합법칙

덧셈과 곱셈은 묶는 순서를 바꾸어도 결과가 같습니다.

(a + b) + c = a + (b + c)
(a × b) × c = a × (b × c)

분배법칙

곱셈은 덧셈에 대해 분배됩니다.

a × (b + c) = a × b + a × c

예

컴퓨터 표현

실수 표현의 한계

컴퓨터는 실수를 정확히 무한히 저장할 수 없으므로 근삿값으로 저장합니다.

double x = 0.1 + 0.2; // 수학적으로는 0.3이지만 컴퓨터 내부에서는 아주 작은 오차가 생길 수 있음

실수 비교는 == 대신 오차 범위를 두고 비교하는 것이 안전합니다.

코딩 연결

C언어로 진법 출력하기

C언어에서는 서식 지정자를 이용해 8진수와 16진수를 출력할 수 있습니다.

#include <stdio.h> int main() { int n = 255; printf("10진수: %d\n", n); printf("8진수: %o\n", n); printf("16진수: %X\n", n); return 0; }

1장 핵심 정리와 연습 과제

핵심 정리

  1. 수의 체계는 수를 성질에 따라 분류한다.
  2. 진법은 자리값과 밑으로 이해한다.
  3. 2진수, 8진수, 16진수는 컴퓨터와 밀접하다.
  4. 컴퓨터는 비트와 바이트로 수를 저장한다.
  5. 2의 보수는 음수 표현의 핵심이다.
