학생들은 염소를 다시 데리고 돌아오는 수를 좀처럼 떠올리지 못합니다. 막히면 답을 주지 말고 "건너간 것을 다시 데려올 수도 있나요?"만 물어보세요. 그 한 마디로 대부분 풀어냅니다.

1-1정답 · 7번
최단 해 (7번) 1. 염소를 태우고 건넘 (남은 쪽: 늑대·양배추 → 안전) 2. 혼자 돌아옴 3. 늑대를 태우고 건넘 4. 염소를 다시 태우고 돌아옴 ← 이 수가 핵심! 5. 양배추를 태우고 건넘 (남은 쪽: 염소 혼자) 6. 혼자 돌아옴 7. 염소를 태우고 건넘 → 완료 또 하나의 7번 해 (3·5번만 바뀜) 염소 → 혼자 → 양배추 → 염소 → 늑대 → 혼자 → 염소

4번 수에서 학생들이 놀랍니다. "왜 애써 건넌 걸 다시 가져와?"라는 반응이 나오면 수업이 잘 되고 있는 것입니다.

1-2정답 · 염소
· 늑대를 먼저 태우면 → 염소와 양배추가 남음 → 염소가 양배추를 먹음 ✗
· 양배추를 먼저 태우면 → 늑대와 염소가 남음 → 늑대가 염소를 먹음 ✗
· 염소를 먼저 태우면 → 늑대와 양배추가 남음 → 아무 일 없음 ✓

그러므로 첫 수는 염소뿐입니다. 선택의 여지가 없습니다.

염소가 양쪽 모두와 문제를 일으키는 유일한 대상이라는 점을 짚어 주세요. 그래서 염소가 계속 배를 타고 오가게 됩니다.

1-3정답 · 10가지
전체 배치 = 2⁴ = 16가지 (넷이 각각 어느 쪽에 있는가) 위험한 배치 6가지 · 농부 없는 쪽에 늑대와 염소가 함께 → 4가지 · 농부 없는 쪽에 염소와 양배추가 함께 → 4가지 · 두 조건이 동시에 걸리는 경우 2가지를 중복 제거 → 4 + 4 − 2 = 6 안전한 배치 = 16 − 6 = 10가지

포함배제가 여기서도 쓰인다는 점을 짚으면 앞 단원(집합론)과 자연스럽게 연결됩니다.

1-4토론 정리

예상 답과 되물음

① 7번짜리 해는 몇 가지인가

정확히 2가지입니다. 첫 수(염소)와 마지막 수는 고정되어 있고, 3번째 수에서 늑대냐 양배추냐만 갈립니다. 두 해는 늑대와 양배추의 역할을 맞바꾼 대칭 관계입니다. → 되물음: "두 방법이 완전히 다른 아이디어인가요, 같은 아이디어인가요?"

② 가장 어려운 수

4번째 수(염소를 다시 데려오기)입니다. 우리는 문제를 풀 때 "진전"만 생각하는데, 이 문제는 일시적으로 후퇴해야 풀립니다. 이런 구조는 퍼즐뿐 아니라 실제 문제 해결에서도 자주 나타납니다.

③ 규칙을 바꾸면

배에 2개를 실을 수 있으면 3번이면 됩니다(염소+늑대 → 염소 데리고 복귀 → 염소+양배추). 늑대가 양배추도 먹는다면 여전히 7번에 가능합니다. 그러나 셋 다 서로 먹는다면 불가능합니다. 하나만 데려갈 수 있는데 남는 둘이 반드시 충돌하기 때문입니다. → 되물음: "불가능하다는 걸 어떻게 확신할 수 있나요?"

④ 컴퓨터로 풀게 하려면

배치(상태)를 네 개의 0/1로, 움직임을 "농부 쪽을 뒤집고 필요하면 하나를 함께 뒤집기"로 표현하면 됩니다. 그러면 컴퓨터는 안전한 10개 상태를 잇는 지도에서 최단 경로를 찾으면 됩니다. 실제로 이 검증도 그 방식(너비 우선 탐색)으로 했습니다.

앞 단원의 쾨니히스베르크 다리와 마찬가지로, 문제를 점과 선으로 바꾸는 순간 컴퓨터가 풀 수 있게 됩니다.

학생끼리 먼저 여러 판 대결하게 하세요. 이길 때와 질 때의 차이를 몸으로 느낀 뒤에 표를 그려야 의미가 있습니다. "돌이 4개 남으면 어떻게 되나요?"가 결정적인 질문입니다.

2-1정답 · 1개
21개에서 시작 → 21 ÷ 4 = 5 … 1 처음에 1개를 가져가 20개(4의 배수)를 남긴다 이후 전략 : 상대가 k개를 가져가면 나는 4−k개를 가져간다 상대 1개 → 나 3개 (합 4) 상대 2개 → 나 2개 (합 4) 상대 3개 → 나 1개 (합 4) → 한 바퀴마다 정확히 4개씩 줄어 20 → 16 → 12 → 8 → 4 → 0 → 마지막 돌은 항상 내가 가져감

남은 돌0123456789101112
내 차례면패승승승패승승승패승승승패

패배 지점이 0, 4, 8, 12, … 로 반복됩니다. 상대에게 4의 배수를 넘기는 것이 필승 전략입니다.
2-3정답 · 후공 승리
님 게임 (1, 2, 3) — 이진수로 쓰고 XOR 무더기 1 : 1 = 001 무더기 2 : 2 = 010 무더기 3 : 3 = 011 ───────────────────── XOR 합 = 000 (= 0) XOR = 0 → 지금 차례인 사람(선공)이 진다 왜? 어떤 수를 둬도 XOR이 0이 아니게 되고, 상대는 다시 0으로 되돌릴 수 있기 때문. (6가지 수 모두 확인 완료) 반대로 (3, 4, 5)는 3 = 011, 4 = 100, 5 = 101 → XOR = 010 (= 2) ≠ 0 → 선공 승리 이기는 수 : 1번 무더기에서 2개 제거 → (1, 4, 5) → XOR = 0
부통의 정리(1901) — 모든 무더기의 XOR이 0이면 지금 차례가 패배, 0이 아니면 승리입니다. 이기는 방법은 항상 XOR을 0으로 만드는 수를 두는 것입니다.
2-4토론 정리

예상 답과 되물음

① 최대 k개까지 가져갈 수 있다면

(k+1)의 배수를 상대에게 남기면 이깁니다. 최대 2개면 3의 배수, 최대 4개면 5의 배수입니다. 이유는 같습니다 — 상대가 k개를 가져가면 나는 (k+1)−k개를 가져가 한 바퀴에 정확히 k+1개씩 줄이면 되기 때문입니다.

전수 확인: 최대 2개 → 패배 지점 0, 3, 6, 9, 12 / 최대 5개 → 0, 6, 12, 18, 24. → 되물음: "왜 하필 k+1일까요? 한 바퀴에 몇 개가 줄어드나요?"

② 마지막을 가져가면 지는 규칙

전략이 한 칸 밀립니다. 이제는 상대에게 1개를 남기는 것이 목표이므로, "4로 나눠 1이 남는 수"를 상대에게 넘겨야 합니다. 선공이 지는 지점은 1, 5, 9, 13, 17, 21입니다.

이런 뒤집힌 규칙을 미제르(misère) 게임이라 부릅니다. 구조는 같고 목표 지점만 이동한다는 점이 핵심입니다. → 되물음: "21개로 시작하면 이번엔 누가 이기나요?" (21 = 4×5+1이므로 선공이 집니다)

③ 이진수의 공통점

선공이 지는 배치는 각 자릿수마다 1의 개수가 짝수입니다. 예를 들어 (1,2,3) = 001, 010, 011에서 1의 자리에 1이 두 개, 2의 자리에 1이 두 개 — 모두 짝수입니다. 이것이 곧 XOR = 0입니다.

"짝을 이룬다"는 발상은 앞 단원의 도미노 색칠이나 약수의 짝짓기와 같은 아이디어입니다. → 되물음: "짝이 맞으면 왜 불리할까요?" (상대가 항상 짝을 복원할 수 있기 때문)

④ 운이 없는 게임의 재미

이런 게임을 완전 정보 게임이라 하며, 이론상 승패가 처음부터 정해져 있습니다. 그런데도 재미있는 이유는 사람이 최적수를 모두 계산하지 못하기 때문입니다. 바둑과 체스도 같은 부류입니다.

전략을 아는 사람이 지는 자리에서 시작하면 어떻게 해야 할까요? 최선은 상대가 실수하기를 기다리는 것입니다. 그래서 일부러 복잡한 수를 두기도 합니다.

2-5정답 · 이기는 첫 수가 없다 (선공 패배)
돌 100개, 한 번에 1~4개 지는 자리 = 5의 배수 (5, 10, 15, …) 100 ÷ 5 = 20 … 0 → 100은 이미 5의 배수 → 선공이 진다 → 무엇을 가져가도 상대에게 5의 배수를 남길 수 없음 이 문제는 "첫 수를 구하라"는 물음 자체가 함정입니다. 답이 없다는 것을 알아내는 것이 정답입니다.

  • 21개에서 3개를 가져감 — 18을 남기는데 18은 4의 배수가 아닙니다. 나머지 계산을 짚어 주세요.

먼저 손을 들어 투표시키세요. 대부분 "50 대 50"이라고 답합니다. 그 상태에서 표를 만들게 하면 스스로 무너집니다. 설득이 잘 안 되면 문 100개 버전을 꺼내세요 — 가장 효과적인 설명입니다.

3-1정답 · 2/3 (바꾸기), 1/3 (유지)
전수 계산 (자동차 위치 3 × 처음 선택 3, 사회자 규칙 반영) 유지 승률 = 1/3 ≈ 33.33% 바꾸기 승률 = 2/3 ≈ 66.67% 몬테카를로 200,000회 유지 33.29% 바꾸기 66.71% → 이론값과 일치

학생들이 직접 20~30번 해 보면 대략 2:1의 차이가 눈에 보입니다. 횟수가 적으면 흔들리므로, 여러 학생의 기록을 합치게 하면 좋습니다.

3-2세 경우로 보는 증명
자동차내 선택사회자가 여는 문유지하면바꾸면
1번1번2 또는 3번자동차 ✓염소 ✗
2번1번3번 (강제)염소 ✗자동차 ✓
3번1번2번 (강제)염소 ✗자동차 ✓
핵심 — 처음에 염소를 골랐다면(확률 2/3) 사회자는 남은 염소 문을 열 수밖에 없고, 그러면 남은 문은 반드시 자동차입니다. 즉 처음에 틀렸을 때 바꾸면 반드시 이깁니다.

처음에 맞힐 확률 = 1/3 → 유지가 이길 확률 = 1/3
처음에 틀릴 확률 = 2/3 → 바꾸면 이길 확률 = 2/3

2번과 3번 줄에서 사회자에게 선택의 여지가 없다는 점이 결정적입니다. 여기서 정보가 새어 나옵니다.

3-3정답 · 99/100
문이 n개, 사회자가 염소 문 (n−2)개를 열어 줄 때 유지 : 1/n 바꾸기 : (n−1)/n 문 3개 → 유지 1/3 (33.33%) · 바꾸기 2/3 (66.67%) 문 4개 → 유지 1/4 (25.00%) · 바꾸기 3/4 (75.00%) 문 10개 → 유지 1/10 (10.00%) · 바꾸기 9/10 (90.00%) 문 100개 → 유지 1/100 (1.00%) · 바꾸기 99/100 (99.00%)

문 100개 버전이 가장 강력한 설명입니다. "내가 처음에 1%의 확률로 맞혔을까, 아니면 남은 저 문일까?"를 물으면 대부분 즉시 이해합니다.

3-4토론 정리

예상 답과 되물음

① 왜 그렇게 많은 사람이 틀렸나

우리 직관은 "선택지가 둘이면 반반"이라고 자동으로 계산합니다. 그러나 확률은 선택지의 개수가 아니라 그 상황에 이르는 경로로 정해집니다. 두 문이 남았지만 거기까지 오는 길의 수가 다릅니다.

1990년 사반트의 칼럼에는 1만 통의 항의가 쏟아졌고 그중 상당수가 박사 학위자였습니다. 전문가도 직관에 속는다는 좋은 사례입니다. → 되물음: "똑똑한 사람들이 왜 더 강하게 확신했을까요?"

② 사회자가 모른다면 (가장 중요)

확률이 달라집니다. 이때는 50 대 50입니다.

사회자가 무작위로 열면 자동차가 나올 수도 있습니다. 그런 경우를 제외하고 "우연히 염소가 나온" 경우만 모으면, 유지 6/12 = 1/2, 바꾸기 6/12 = 1/2가 됩니다.

즉 이 문제의 정답을 만드는 것은 문의 개수가 아니라 "사회자가 알고서 반드시 염소 문을 연다"는 규칙입니다. 문제를 낼 때 이 조건을 빼먹으면 답이 달라집니다. → 되물음: "조건 하나가 답을 바꾼다면, 문제를 읽을 때 무엇을 확인해야 할까요?"

③ "두 개 남았으니 반반"의 오류

경우의 수가 둘이라고 확률이 같은 것은 아닙니다. "내일 비가 온다 / 안 온다"도 두 가지지만 반반이 아닙니다. 확률은 경우의 가짓수가 아니라 각 경우가 일어나는 정도로 정해집니다.

여기서는 처음 선택의 1/3이 끝까지 변하지 않는다는 점이 핵심입니다. 사회자는 내 문에 대해서는 아무 정보도 주지 않았습니다.

④ 어떤 설명이 잘 통하나

경험적으로 문 100개 설명이 가장 효과적이고, 그다음이 표 만들기입니다. 직접 100번 해 보기는 시간이 걸리지만 의심하는 학생을 설득하는 데는 가장 확실합니다. 셋을 순서대로 쓰는 것이 좋습니다.

  • "바꾸든 말든 똑같다" — 위와 같은 원인입니다. 세 경우 표를 직접 채우게 하세요.
  • 사회자 조건을 놓침 — 사회자가 무작위로 열었다면 실제로 50 대 50입니다. 틀린 게 아니라 다른 문제를 푼 것이므로, 조건의 중요성을 짚어 주세요.

이유는 배신이 상대의 협력을 파괴해 판 전체를 작게 만들기 때문입니다. 협력하는 상대끼리는 매 회 3+3 = 6점을 나눠 갖지만, 서로 배신하면 1+1 = 2점뿐입니다.

4-4토론 정리

예상 답과 되물음

① 한 번과 반복의 차이

미래가 생겼기 때문입니다. 한 번만 만나면 배신의 대가를 치를 일이 없지만, 반복하면 오늘의 배신이 내일 돌아옵니다. 팃포탯 상대로 배신하면 그다음부터 계속 1점씩만 받게 됩니다.

실제로 팃포탯 vs 항상배신은 199 대 204로, 팃포탯이 첫 회에만 당하고 이후로는 똑같이 1점씩 받습니다. 5점 차이는 첫 회 손해뿐입니다. → 되물음: "마지막 회라는 걸 서로 안다면 어떻게 될까요?" (마지막엔 배신이 유리해지고, 그 논리가 거꾸로 번져 갑니다)

② 팃포탯이 강한 이유

액설로드가 정리한 네 가지 성질입니다.

· 먼저 배신하지 않는다(신사적) — 협력하는 상대와 최대 점수를 나눔
· 보복한다 — 당하면 바로 갚아 이용당하지 않음
· 용서한다 — 상대가 돌아오면 바로 협력 재개
· 단순하다 — 상대가 내 전략을 쉽게 파악해 협력하기 쉬움

앙심은 한 번 배신당하면 영원히 보복하므로 용서가 없습니다. 이 실험에서는 동점이지만, 실수가 섞이는 현실에서는 팃포탯이 훨씬 유리합니다. → 되물음: "실수로 한 번 배신했다면 두 전략의 결과가 어떻게 달라질까요?"

③ 주변의 같은 구조

· 교실 청소 — 모두 열심히 vs 모두 대충
· 조별 과제 — 무임승차가 대표적
· 새치기·줄서기 — 모두 지키면 빠르지만 혼자 어기면 이득
· 환경 문제 — 각 나라가 배출을 줄이면 모두 이득이지만 혼자 줄이면 손해

공통점은 "혼자 협력하면 손해, 모두 배신하면 다 같이 나쁨"입니다.

④ 딜레마를 벗어나는 방법

모두 게임의 구조 자체를 바꾸는 방법입니다.

· 반복해서 만나기 — 미래의 보복을 가능하게 함 (가장 강력)
· 평판 남기기 — 배신하면 다른 사람과의 게임에도 영향
· 규칙과 벌칙 — 배신의 보수를 낮춰 아예 우월 전략이 아니게 만듦
· 약속하기 — 강제력이 없으면 효과가 약함

조별 과제에서 중간 점검과 상호 평가를 넣는 것이 곧 "반복 게임으로 바꾸기"입니다.

  • 보수 표에서 큰 숫자를 좋은 것으로 읽음 — 형량은 적을수록 좋습니다. 표 상단에 반드시 명시하세요.
  • "항상 배신이 최고 전략" — 개별 대결만 보면 그렇게 보입니다. 총점을 보게 하세요.

지도 요령

학생들은 1번 단서부터 순서대로 쓰려다 헤맵니다. "어떤 단서가 위치를 바로 알려 주나요?"를 먼저 물어 8번과 9번을 찾게 하세요. 뼈대가 서면 나머지는 빠르게 풀립니다. 40~50분이 걸리는 큰 과제이므로 모둠 활동으로 권합니다.

물고기 → 프랑스, 물 → 영국, 고양이 → 수학입니다. 이 표가 15개 단서를 모두 만족하는 유일한 답임이 전수 탐색으로 확인되었습니다.

5-2정답 · 8번과 9번
단서의 세 종류
· 위치 확정형 (8번 가운데=우유, 9번 영국인=1번 집) → 가장 먼저
· 속성 연결형 (1번 한국인=빨강, 5번 초록=커피 등) → 위치가 정해지면 연쇄적으로 확정
· 이웃 관계형 (10, 11, 14, 15번) → 후보가 여러 개라 나중에 쓰는 것이 효율적

다만 14번(영국인은 파란집 옆)은 9번과 결합하면 즉시 위치를 확정하므로 예외적으로 일찍 씁니다.
5-3정답 · 파랑
추론의 시작 (색깔 뼈대 세우기) ① 단서 9 : 영국인 = 1번 집 ② 단서 14 : 영국인은 파란집 옆 1번이 파랑이면 자기 자신 옆이 되어 모순 → 2번이 파랑 ③ 단서 8 : 3번이 우유 ④ 단서 4 : 초록은 하양 바로 오른쪽 → (하양,초록) = (3,4) 또는 (4,5) 단서 5 : 초록집은 커피. 그런데 3번은 우유이므로 초록은 3번이 아니다 → (하양, 초록) = (4번, 5번) ⑤ 남은 색 빨강·노랑은 1번·3번 단서 1 : 한국인 = 빨강. 1번은 영국인이므로 1번은 빨강이 아니다 → 3번 빨강, 1번 노랑 색이 모두 확정 : 노랑 · 파랑 · 빨강 · 하양 · 초록

여기까지 오면 나머지는 도미노처럼 풀립니다. 문제집의 단계별 보기 도구에 12단계 전 과정이 담겨 있습니다.

5-4토론 정리

예상 답과 되물음

① 답이 하나뿐임을 어떻게 아나

하나를 찾는 것과 그것뿐임을 아는 것은 다릅니다. 유일성을 보이려면 ① 모든 경우를 검사하거나, ② 각 단계에서 선택의 여지가 없었음을 보여야 합니다.

5-3의 추론이 후자입니다. 매 단계에서 "이것 말고는 불가능"을 확인했으므로 답이 하나임이 따라옵니다. 앞 단원의 강 건너기 첫 수와 같은 논법입니다. → 되물음: "우리가 푼 과정에서 '선택'을 한 적이 있나요?"

② 단서를 빼면 (놀라운 발견)

대부분의 단서는 빼면 답이 여러 개가 됩니다. 특히 9번(영국인=1번 집)을 빼면 17개로 늘어납니다.

그런데 15번(미술은 물 옆집)은 빼도 답이 여전히 하나입니다! 즉 이 단서는 없어도 되는 잉여 단서입니다. 문제를 만든 사람도 몰랐을 수 있습니다.

이것은 학생들이 매우 좋아하는 발견입니다. "주어진 정보를 다 써야 한다"는 법은 없다는 교훈이기도 합니다. → 되물음: "시험 문제에서 안 쓰는 조건이 있으면 불안한가요? 왜 그럴까요?"

③ 모든 경우를 다 해 본다면

5개 항목이 각각 5! = 120가지이므로 120⁵ = 약 249억 가지입니다. 사람이 하나씩 확인하는 것은 불가능합니다. 컴퓨터도 그냥 다 해 보면 오래 걸려서, 단계마다 가지치기를 해야 빨라집니다(이 검증도 그렇게 했습니다).

사람이 푸는 방식(단서로 후보를 좁히기)이 사실은 컴퓨터의 가지치기와 같은 아이디어입니다.

④ "아인슈타인이 만들었다"는 주장

근거가 없습니다. 가장 오래된 기록은 1962년 『Life International』이고 아인슈타인은 1955년에 세상을 떠났습니다. "2%만 푼다"는 수치도 출처가 없습니다.

유명한 사람의 이름을 붙이면 그럴듯해 보이는 현상은 흔합니다. 출처를 확인하는 습관을 이야기하기 좋은 소재입니다. → 되물음: "이런 주장을 어떻게 확인해 볼 수 있을까요?"

5-5정답 · 물=영국 / 고양이=수학
완성된 표에서 읽어내기 물을 마시는 사람 → 1번 집 영국인 고양이를 기르는 사람 → 1번 집 → 좋아하는 과목 수학 물고기를 기르는 사람 → 5번 집 프랑스인 원전(제브라 퍼즐)에서도 같은 구조로 "물을 마시는 사람"과 "얼룩말을 기르는 사람"을 묻습니다.

흔한 오답과 원인

  • 1번 단서부터 순서대로 적용 — 가장 흔한 시행착오입니다. 8·9번을 먼저 쓰게 안내하세요.
  • "바로 오른쪽"을 "오른쪽 어딘가"로 읽음 — 단서 4의 해석 오류로 답이 전혀 달라집니다.
  • "옆집"을 한 방향으로만 봄 — 옆집은 양쪽 모두입니다.
  • 추측으로 채우고 검산하지 않음 — 반드시 15개 단서를 모두 대조하게 하세요.
  • 중간에 모순이 나면 처음부터 다시 시작 — 모순이 난 지점의 선택만 되돌리면 됩니다(되추적).
