SET 01

늑대와 염소와 양배추를 무사히 건너게 하려면

원전 · 강 건너기 문제 — 알퀸 『청년의 마음을 단련하는 문제집』(799년경), 기록에 남은 가장 오래된 논리퍼즐 중 하나

난이도 ★★☆상태 탐색되돌아가기최단 해
1-1탐색
상황 — 농부가 늑대, 염소, 양배추를 데리고 강을 건너려 합니다. 배에는 농부와 하나만 탈 수 있습니다. 농부가 없으면 늑대는 염소를, 염소는 양배추를 먹습니다.

모두 무사히 건너려면 어떻게 해야 할까요? 아래에서 직접 배를 움직여 보세요.

1-2추론

맨 처음에 무엇을 태워야 할까요? 세 가지를 모두 따져 보세요.

  • 늑대를 먼저 태우면 → 남는 것은 염소와 양배추 → 어떻게 되나요?
  • 양배추를 먼저 태우면 → 남는 것은 늑대와 염소 → 어떻게 되나요?
  • 염소를 먼저 태우면 → 남는 것은 늑대와 양배추 → 괜찮나요?
중요한 발견
이 퍼즐의 핵심은 염소를 다시 데리고 돌아오는 수입니다. "건너간 것을 되돌린다"는 생각을 하지 못하면 절대 풀리지 않습니다.

규칙 — 돌 21개가 있습니다. 두 사람이 번갈아 1개, 2개, 3개 중 원하는 만큼 가져갑니다. 마지막 돌을 가져가는 사람이 이깁니다.

2-2추론

거꾸로 생각해 봅시다. 내 차례에 돌이 몇 개 남아 있으면 지는 걸까요?

  • 돌이 1, 2, 3개 남으면? → 전부 가져가면 이깁니다.
  • 돌이 4개 남으면? → 몇 개를 가져가도 상대에게 1~3개가 남습니다. 그럼 상대가 이깁니다.
  • 돌이 5, 6, 7개 남으면? → 상대에게 4개를 남길 수 있으므로 이깁니다.
  • 돌이 8개 남으면? → 어떻게 해도 상대에게 5~7개를 남기게 됩니다.

2-4토론

  1. 규칙을 바꿔 최대 5개까지 가져갈 수 있다면 필승 전략이 어떻게 바뀔까요? 최대 k개라면 일반적으로 어떻게 될까요?
  2. 이번엔 마지막 돌을 가져가면 지는 규칙(31 게임)으로 바꿔 봅시다. 전략이 어떻게 달라지나요? 어디가 똑같고 어디가 다른가요?
  3. 님 게임에서 각 무더기를 이진수로 쓰고 자릿수별로 개수를 세어 보세요. 선공이 지는 배치들의 공통점이 보이나요?
  4. 이런 게임은 운이 전혀 없습니다. 그런데도 사람들이 재미있어하는 이유는 무엇일까요? 상대가 전략을 모른다면 어떻게 될까요?
2-5도전

돌이 100개이고 한 번에 1~4개를 가져갈 수 있습니다(마지막을 가져가면 승). 선공이 이기려면 처음에 몇 개를 가져가야 할까요?

general-strategy
함정 주의
최대 4개면 5의 배수를 남겨야 이깁니다. 그런데 100은 이미 5의 배수입니다. 이 경우 선공은 어떻게 될까요?

출처 — 뺏기 게임은 바셰가 1612년 『재미있고 즐거운 문제들』에 실었고, 여러 무더기를 다루는 님은 찰스 부통이 1901년 논문에서 이진법 XOR로 완전한 필승법을 증명했습니다. 조합 게임 이론의 출발점입니다.

SET 03

문을 바꾸는 게 정말 유리할까

원전 · 몬티 홀 문제 — 1990년 마릴린 보스 사반트의 칼럼으로 세계적 논쟁을 일으킨 확률 문제

난이도 ★★★조건부 확률직관 깨기숨은 조건
3-1탐색
상황 — 문 세 개 중 하나 뒤에는 자동차, 나머지 둘 뒤에는 염소가 있습니다. 당신이 문 하나를 고르면, 어디에 무엇이 있는지 아는 사회자가 남은 두 문 중 염소가 있는 문을 하나 열어 줍니다. 그리고 묻습니다. "선택을 바꾸시겠습니까?"

바꾸는 게 유리할까요, 그대로가 유리할까요? 아래에서 직접 여러 번 해 보고 기록을 확인하세요.

monty-hall
문을 하나 골라 보세요.
3-2추론

왜 그럴까요? 처음 선택에만 집중해 보세요.

  • 처음에 자동차를 골랐을 확률은? → 이때 바꾸면 어떻게 되나요?
  • 처음에 염소를 골랐을 확률은? → 이때 사회자는 남은 염소 문을 열 수밖에 없습니다. 그럼 바꾸면?
  • 두 경우를 합치면 바꿔서 이길 확률은 얼마인가요?
three-cases
처음 선택을 1번 문으로 고정하고 자동차 위치만 바꿔 봅니다.
이해를 돕는 생각
처음 선택은 1/3의 확률로 맞습니다. 그렇다면 "내가 안 고른 두 문"에 자동차가 있을 확률은 2/3입니다. 사회자가 그중 염소 문 하나를 치워 줬을 뿐이므로, 그 2/3이 남은 한 문에 몰립니다.

문이 100개라면 어떨까요? 당신이 하나를 고르면 사회자가 98개의 염소 문을 열어 줍니다. 이제 바꾸시겠습니까?

SET 04

둘 다 똑똑하게 굴었는데 둘 다 손해를 봤다

원전 · 죄수의 딜레마 — 1950년 플러드와 드레셔가 고안하고 터커가 이름 붙인 게임이론의 대표 문제

난이도 ★★☆보수 행렬우월 전략협력과 배신
4-1탐색
상황 — 두 사람이 따로 떨어져 조사를 받습니다. 서로 의논할 수 없습니다.
· 둘 다 침묵하면 → 각각 1년
· 한 명만 자백하면 → 자백한 사람 0년, 침묵한 사람 10년
· 둘 다 자백하면 → 각각 5년

당신이라면 어떻게 하시겠습니까? 아래 표에서 칸을 눌러 각 경우의 결과를 확인하세요.

payoff-matrix
숫자는 형량(년)입니다. 적을수록 좋습니다.
4-2추론

둘 다 똑똑하게 자기에게 유리한 선택을 하면 어떻게 될까요?

  • 두 사람 모두 자백을 선택합니다. 결과는 각자 몇 년인가요?
  • 만약 둘 다 침묵했다면 각자 몇 년이었을까요?
  • 둘 다 더 좋아지는 방법이 있는데도 왜 그렇게 되지 않을까요?
딜레마 — 각자에게 합리적인 선택이 모여, 모두에게 나쁜 결과가 나옵니다. 이것이 이 문제가 유명한 이유입니다.
4-3확장

이 게임을 한 번만 하는 게 아니라 여러 번 반복한다면 어떻게 될까요? 여러 전략을 대결시켜 보세요.

repeated-game
점수는 높을수록 좋습니다 (둘 다 협력 3점, 배신 성공 5점, 당함 0점, 둘 다 배신 1점).
4-4토론

모둠에서 이야기해 봅시다

  1. 한 번만 하는 게임에서는 배신이 유리한데, 반복하면 협력하는 전략이 이깁니다. 무엇이 달라졌기 때문일까요? "다음에 또 만난다"는 사실이 왜 중요한가요?
  2. 팃포탯(처음엔 협력, 그다음부터는 상대가 한 대로 따라 하기)이 강한 이유는 무엇일까요? 이 전략의 네 가지 성질(먼저 배신 안 함 / 보복함 / 용서함 / 단순함)을 찾아보세요.
  3. 우리 주변에서 죄수의 딜레마와 같은 구조를 찾아보세요. 예: 교실 청소, 조별 과제, 새치기, 환경 문제. 각각 무엇이 "협력"이고 무엇이 "배신"인가요?
  4. 딜레마를 벗어나는 방법은 무엇일까요? 서로 약속하기, 규칙 만들기, 평판 남기기, 반복해서 만나기 중 어느 것이 효과적일까요?
4-5적용

우리 반 상황으로 바꿔 봅시다. 모둠 과제에서 "열심히 하기"와 "묻어가기" 중 고른다면 보수 표가 어떻게 될까요? 직접 채워 보세요.

make-your-own
직접 만들어 본 뒤 예시와 비교해 보세요.

출처 — 1950년 랜드연구소의 메릴 플러드와 멜빈 드레셔가 실험으로 고안했고, 앨버트 터커가 죄수 이야기로 각색해 이름을 붙였습니다. 1980년 로버트 액설로드의 반복 게임 대회에서 팃포탯이 우승하며 협력의 조건에 대한 연구가 크게 발전했습니다.

SET 05

다섯 집 수수께끼 — 물고기는 누가 기르는가

원전 · 제브라 퍼즐 / 아인슈타인의 수수께끼 — 논리 격자 퍼즐의 대표작 (1962년 『Life International』)

상황 — 다섯 채의 집이 나란히 있습니다. 각 집은 색이 다르고, 사는 사람의 나라가 다르고, 마시는 음료가 다르고, 기르는 동물이 다르고, 좋아하는 과목이 다릅니다. 아래 15개 단서로 물고기를 기르는 사람의 나라를 알아내세요.

어떤 단서부터 써야 할까요? 단서를 확실한 것과 관계만 알려 주는 것으로 나눠 보세요.

  • 위치를 바로 정해 주는 단서는 무엇인가요? (예: "가운데 집은 우유")
  • 두 가지를 묶어 주는 단서는? (예: "한국인은 빨간 집")
  • "옆집"만 알려 주는 단서는 왜 나중에 쓰는 게 좋을까요?

5-4토론

모둠에서 이야기해 봅시다

  1. 이 퍼즐의 답은 단 하나입니다. 답이 하나뿐이라는 것을 어떻게 확인할 수 있을까요? 하나를 찾은 것과 그것뿐임을 아는 것은 어떻게 다른가요?
  2. 단서 하나를 빼면 어떻게 될까요? 답이 여러 개가 될까요, 아니면 그대로일까요? 아래 도구로 확인해 보세요.
  3. 이 문제를 모든 경우를 다 해 보는 방법으로 풀면 몇 가지를 확인해야 할까요? (5개 항목 각각 5!가지) 사람이 그렇게 풀 수 있을까요?
  4. "아인슈타인이 만들었고 세계 인구의 2%만 푼다"는 말이 흔히 붙어 있습니다. 이런 주장은 믿을 만할까요? 어떻게 확인해 볼 수 있을까요?
