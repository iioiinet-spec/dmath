알콰리즈미는 넓이 그림으로 풀었습니다. 아래에서 한 단계씩 따라가 보세요.

completing-the-square
3-2추론

그림에서 한 일을 식으로 옮겨 봅시다.

x² + 10x = 39
x² + 10x + ___ = 39 + ___   ← 양변에 같은 수를 더한다
(x + ___)² = ___
x + 5 = ___  →  x = ___

비밀 — 더해야 할 수는 (x의 계수 ÷ 2)의 제곱입니다. 여기서는 (10 ÷ 2)² = 25.

왜 하필 그 수일까요? 그림에서 모서리에 채운 정사각형의 한 변을 보세요.

알콰리즈미가 놓친 답
(x+5)² = 64 에서 x + 5 = 8 뿐 아니라 x + 5 = −8도 가능합니다. 그러면 x = −13이 됩니다. 실제로 (−13)² + 10×(−13) = 169 − 130 = 39 로 맞습니다! 그런데 알콰리즈미 시대에는 음수를 수로 인정하지 않아 이 답을 버렸습니다.

3-5도전

알콰리즈미의 책에 나오는 또 다른 문제입니다.

원숭이 문제 — 원숭이 무리가 있습니다. 전체의 1/4을 제곱한 수만큼이 숲에서 놀고, 나머지 3마리는 나무 위에 있습니다. 원숭이는 모두 몇 마리일까요?

식으로 : (x/4)² + 3 = x
푸는 방법
양변에 16을 곱하면 x² + 48 = 16x, 즉 x² − 16x = −48이 됩니다. 완전제곱으로 (x − 8)² = −48 + 64 = 16 이므로 x − 8 = ±4 입니다.

왜 정사각형일 때 최대일까요? 식으로 확인해 봅시다.

넓이 = x(20 − x) = 20x − x² = −(x² − 20x)
     = −(x² − 20x + 100) + 100  ← 완전제곱 (세트 3과 같은 방법!)
     = −(x − 10)² + 100

(x − 10)²은 항상 0 이상이므로, x = 10일 때 가장 작은 값 0이 되어 넓이가 최대 100이 됩니다.
