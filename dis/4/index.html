SET 01

일곱 개의 다리를 한 번씩만 건널 수 있을까

원전 · 쾨니히스베르크의 다리 문제 (레온하르트 오일러, 1736) — 그래프 이론이 시작된 문제

난이도 ★★☆위상 · 연결불변량한붓그리기
1-1탐색
상황 — 강이 도시를 네 구역(A 북쪽, B 섬, C 남쪽, D 동쪽)으로 나누고, 그 사이를 다리 7개가 잇고 있습니다.

모든 다리를 딱 한 번씩만 건너 도시를 산책할 수 있을까요? 아래 지도에서 다리를 순서대로 눌러 직접 시도해 보세요.

bridge-walk.svg
시작할 육지를 먼저 누르세요.
힌트 보기
여러 번 시도하면 늘 마지막 한 개를 남기고 막힙니다. 실패가 반복된다면 "운이 나쁜 것"이 아니라 "구조상 불가능한 것"일 수 있습니다.
1-2발견

위 지도에서 차수 보기를 누르면 각 육지에 연결된 다리의 개수가 나옵니다. 네 육지의 차수를 적고, 그중 홀수인 곳이 몇 군데인지 세어 보세요.

1-3추론

어떤 육지를 중간에 지나간다고 해 봅시다. 그러려면 다리 하나로 들어가고 다른 다리 하나로 나와야 하므로, 다리가 2개씩 짝을 이루어야 합니다.

  • 중간에 지나가기만 하는 육지의 차수는 짝수여야 한다 — 왜 그런지 설명하세요.
  • 그렇다면 차수가 홀수인 육지는 산책에서 어떤 역할만 할 수 있을까요?
  • 출발점과 도착점은 최대 몇 개인가요? 그러면 홀수 육지는 최대 몇 개까지 허용될까요?
1-4토론

모둠에서 이야기해 봅시다

  1. "여러 번 해 봤는데 안 됐어요"와 "홀수점이 4개라서 불가능해요" — 두 주장은 무엇이 다른가요? 어느 쪽이 증명인가요?
  2. 다리를 1개만 더 놓아 산책을 가능하게 하려면 어디에 놓아야 할까요? 그때 출발점과 도착점은 어디가 되나요?
  3. 출발한 곳으로 돌아오기까지 하려면 다리를 최소 몇 개 더 놓아야 할까요? 이유를 홀수점 개수로 설명하세요.
  4. 이 문제에서 강의 폭이나 다리의 길이는 답에 영향을 줄까요? 그렇다면 이 문제가 다루는 "모양"은 무엇인가요?
1-5적용

아래 도형들을 연필을 떼지 않고 같은 선을 두 번 긋지 않으며 그릴 수 있는지, 직접 그려 보기 전에 홀수점을 세어 예측하세요. 그런 다음 그려서 확인합니다.

one-stroke.svg
판정 규칙 정리하기
홀수점 0개 → 어디서 출발해도 되고 제자리로 돌아온다. 홀수점 2개 → 한 홀수점에서 출발해 다른 홀수점에서 끝난다. 홀수점 4개 이상 → 불가능. (홀수점은 항상 짝수 개입니다. 왜일까요?)

출처 — Euler, Solutio problematis ad geometriam situs pertinentis (1736). 오일러는 이 문제를 풀며 "길이와 각도가 아니라 연결 관계만 따지는 기하"라는 새로운 분야를 열었습니다.

SET 02

모서리 두 칸이 사라진 체스판

원전 · 잘린 체스판 문제 (Max Black, 『Critical Thinking』 1946) — 색칠 논법의 대표 사례

난이도 ★★☆타일링색칠 논법불가능 증명
2-1탐색
상황 — 8×8 체스판에서 서로 마주 보는 대각선 끝 두 칸을 잘라냈습니다. 남은 칸은 62칸입니다. 1×2 크기 도미노 31개로 남은 칸을 빈틈없이, 겹치지 않게 덮을 수 있을까요?

아래 판에서 칸을 두 번 클릭(또는 드래그)해 도미노를 놓아 보세요. 최대 몇 개까지 놓을 수 있나요?

domino-board.svg
놓은 도미노 0개 · 덮은 칸 0 / 62
2-2발견

도미노 하나를 어디에 어떻게 놓든, 그것이 덮는 검은 칸과 흰 칸의 개수는 각각 몇 개인가요? 가로로 놓든 세로로 놓든 항상 그런지 확인하세요.

그렇다면 도미노 31개가 덮는 검은 칸은 몇 개, 흰 칸은 몇 개일까요?

힌트 보기
도미노는 반드시 변을 맞대고 있는 두 칸을 덮습니다. 체스판에서 변을 맞댄 두 칸의 색은 어떤 관계인가요?
2-3추론

2-2에서 찾은 사실 두 가지를 이어 붙여 "덮는 것이 불가능하다"는 증명을 완성하세요. 다음 뼈대를 채우면 됩니다.

  1. 도미노 1개는 흰 칸 ___ 개와 검은 칸 ___ 개를 덮는다.
  2. 따라서 도미노 31개는 흰 칸 ___ 개, 검은 칸 ___ 개를 덮는다.
  3. 그런데 잘린 판에는 흰 칸 ___ 개, 검은 칸 ___ 개가 있다.
  4. 그러므로 ___.
2-4토론

모둠에서 이야기해 봅시다

  1. 체스판의 색깔은 원래 문제와 아무 상관없는 장식처럼 보입니다. 그런데 왜 색이 결정적인 열쇠가 되었을까요?
  2. 이번에는 다른 색 두 칸을 잘라냈습니다. 항상 덮을 수 있을까요? 색이 다르기만 하면 되는지, 위치도 중요한지 위 판에서 실험해 보고 주장을 세우세요.
  3. "색이 같으면 불가능하다"는 것은 증명했습니다. "색이 다르면 가능하다"도 같은 방법으로 증명되나요? 두 문장의 차이를 설명하세요.
  4. 이번엔 1×3 조각으로 8×8 전체를 덮으려 합니다. 색칠하지 않고도 불가능함을 보일 수 있나요?
2-5확장

같은 색 두 칸을 아무 데나 잘라내도 늘 불가능한지, 위 판에서 두 칸을 직접 지정해 확인해 보세요. 반대로 다른 색 두 칸을 잘라낸 경우도 여러 번 실험하고, 관찰한 규칙을 한 문장으로 적으세요.

출처 — Max Black, Critical Thinking (1946). 이후 Golomb(1954), Gamow & Stern(1958)을 통해 널리 알려졌고, 다른 색 두 칸을 제거하면 항상 덮을 수 있다는 사실은 고모리 정리(R. E. Gomory)로 알려져 있습니다.

SET 03

거미가 파리에게 가는 가장 짧은 길

원전 · 거미와 파리 문제 (Henry Dudeney, Weekly Dispatch 1903 / 『The Canterbury Puzzles』) — 전개도로 푸는 최단 경로

난이도 ★★★전개도피타고라스최단 경로
3-1탐색
상황 — 가로 3, 세로 2, 높이 1인 직육면체 상자가 있습니다. 개미가 한 꼭짓점 A에서 대각선 반대쪽 꼭짓점 B까지 겉면을 따라서만 기어갑니다.

먼저 예상해 보세요. 개미가 "위로 올라갔다가 옆으로" 가는 식으로 모서리를 따라가면 3+2+1 = 6입니다. 이보다 짧게 갈 수 있을까요?

아래에서 전개도를 펼치는 방법을 바꿔 가며 직선 경로의 길이를 재어 보세요.

unfold-box.svg
힌트 보기
전개도에서 두 점을 잇는 직선이 곧 최단 경로입니다. 전개하는 방법이 여러 가지라면, 각각의 직각삼각형에서 밑변과 높이가 어떻게 달라지는지 비교하세요.
3-2추론

가로 a, 세로 b, 높이 c인 상자에서 마주 보는 꼭짓점까지의 최단 경로는 세 가지 후보 중 가장 작은 값입니다. 세 후보를 a, b, c로 나타내세요.

  • 후보 1 : √( (___ + ___)² + ___² )
  • 후보 2 : √( (___ + ___)² + ___² )
  • 후보 3 : √( (___ + ___)² + ___² )

세 후보 중 최솟값은 세 변 중 어느 두 변을 더하는지에 따라 결정됩니다. 어느 두 변을 더해야 가장 짧아질까요?

3-3비교

상자 속을 뚫고 지나가는 직선거리(공간 대각선)는 √(a²+b²+c²)입니다. 3×2×1 상자에서 이 값과 겉면 최단 경로를 비교하세요.

3-4토론

모둠에서 이야기해 봅시다

  1. 왜 전개도 위의 직선이 곡면 위 최단 경로가 될까요? 종이를 접었다 폈을 때 변하지 않는 것은 무엇인가요?
  2. 전개하는 방법이 여러 가지인데, 그중 가장 짧은 것 하나만 답이 됩니다. 그렇다면 "모든 전개도를 다 검사했다"는 것을 어떻게 확신할 수 있을까요?
  3. 원기둥 모양 컵의 바깥면을 따라 반대편으로 갈 때도 같은 방법을 쓸 수 있을까요? 구(공)에서는 어떨까요?
  4. 더디니의 원래 문제입니다. 길이 30, 폭 12, 높이 12인 방에서 거미는 한쪽 벽 한가운데 천장에서 1 떨어진 곳에, 파리는 반대편 벽 한가운데 바닥에서 1 떨어진 곳에 있습니다. 천장을 가로지르는 단순한 길은 1+30+11 = 42입니다. 그런데 정답은 40입니다. 어떻게 하면 42보다 짧아질 수 있을까요?
3-5도전

토론 4번의 방(30×12×12)에서 거미가 다섯 개의 면을 밟고 지나가는 길을 전개도로 그려, 직각삼각형의 두 변이 32와 24가 됨을 보이세요. 그 빗변이 40임을 계산으로 확인합니다.

전개 순서 힌트
거미가 있는 벽 → 천장 → 옆벽 → 바닥 → 파리가 있는 벽 순서로 펼칩니다. 펼친 뒤 거미와 파리의 좌표를 잡아 두 점의 가로·세로 차이를 각각 구해 보세요.

출처 — H. E. Dudeney, Weekly Dispatch (1903-06-14), 『The Canterbury Puzzles』(1907). 단순 경로 42보다 짧은 40이 정답이며, 최단 경로가 여섯 면 중 다섯 면을 지난다는 점이 이 문제의 반전입니다.

SET 04

삼각형 안 어디에 서 있든 변하지 않는 것

원전 · 비비아니 정리 (Vincenzo Viviani, 17세기) — 넓이로 증명하는 불변량

난이도 ★★☆넓이 분할불변량일반화
4-1탐색
상황 — 정삼각형 안에 점 P를 하나 찍고, P에서 세 변에 각각 수직으로 선을 내립니다. 그 세 길이를 더합니다.

아래 삼각형에서 점 P를 마음대로 끌어 보세요. 세 거리의 합이 어떻게 변하나요?

viviani.svg
4-2추론

P에서 세 꼭짓점으로 선을 그으면 큰 정삼각형이 작은 삼각형 3개로 나뉩니다. 넓이로 보기를 눌러 확인한 뒤, 다음을 채워 증명하세요.

한 변의 길이를 a, 높이를 h, 세 거리를 d₁, d₂, d₃라 하면
작은 삼각형 세 개의 넓이 합 = ½·a·d₁ + ½·a·d₂ + ½·a·d₃ = ½·a·( ___ )
큰 정삼각형의 넓이 = ½·a·___
두 값이 같으므로 → ___
왜 세 밑변이 모두 a인가요?
세 작은 삼각형의 밑변은 각각 큰 삼각형의 세 변입니다. 정삼각형이므로 세 변의 길이가 모두 같습니다. 이 점이 증명의 핵심이며, 동시에 정삼각형이어야 하는 이유이기도 합니다.
4-3검증

한 변의 길이가 10인 정삼각형 안의 점 P에서 두 변까지의 거리가 각각 2와 3이었습니다. 세 번째 거리는 얼마일까요? (√3 ≈ 1.732로 계산)

4-4토론

모둠에서 이야기해 봅시다

  1. 증명의 어느 단계에서 "정삼각형"이라는 조건을 썼나요? 일반 삼각형이면 왜 무너지나요? 직접 반례를 그려 보세요.
  2. 정사각형으로 버튼을 눌러 보세요. 네 변까지 거리의 합도 일정한가요? 그렇다면 그 값은 무엇과 같나요? 직사각형에서도 성립할까요?
  3. 정오각형, 정육각형에서도 성립할까요? 성립한다면 거리의 합은 어떤 값이 될지 넓이 논법으로 예측하세요.
  4. 점 P가 삼각형 바깥에 있으면 어떻게 될까요? 거리에 부호(+, −)를 붙이면 정리를 살릴 수 있을까요?
4-5확장

이 정리는 화학에서 삼각 그래프로 쓰입니다. 세 성분을 섞은 혼합물을 정삼각형 안의 점 하나로 나타내는 방법입니다. 왜 이 정리가 있어야 그런 표현이 가능한지 설명해 보세요.

출처 — Vincenzo Viviani(1622–1703). 토리첼리가 푼 페르마 점 문제의 해법을 제자 비비아니가 1659년 출판하며 이 사실이 알려졌습니다.

SET 05

직선 몇 개로 피자를 가장 많이 자르기

원전 · 게으른 요리사 수열 (Jakob Steiner, 1826의 평면 분할 문제) — 점화식으로 세는 기하

난이도 ★★★규칙 찾기점화식최댓값 조건
5-1탐색
상황 — 둥근 피자를 곧은 직선으로만 자릅니다. 조각을 옮기거나 겹쳐 자를 수는 없습니다. 조각의 크기는 달라도 됩니다.

직선 3개로 자를 때 조각이 몇 개까지 나올 수 있을까요? 아래 피자를 드래그해 직접 잘라 보고, 최대 조각 수를 찾으세요.

pizza-cut.svg
피자 위에서 드래그하면 칼금이 그어집니다.
힌트 보기
세 직선이 한 점에서 만나면 6조각입니다. 그보다 많이 나오게 하려면 세 직선의 교점이 어떻게 놓여야 할까요?
5-2발견

직선을 0개부터 하나씩 늘려 가며 최대 조각 수를 표로 채우세요. 그런 다음 이웃한 두 수의 차이를 아래 칸에 적습니다.

sequence-table
직접 채워 본 뒤 버튼을 눌러 확인하세요.
5-3추론

왜 n번째 칼이 정확히 n조각을 늘릴까요? 다음 순서로 설명해 보세요.

  1. 새 칼이 기존 n−1개의 칼과 최대 몇 번 만날 수 있나요? (두 직선은 최대 몇 번 만나나요?)
  2. 그 교점들이 새 칼을 몇 개의 조각(선분)으로 나누나요?
  3. 선분 하나가 지나가면 원래 있던 조각 하나가 몇 개로 나뉘나요?
  4. 따라서 늘어나는 조각 수는 ___ 개입니다.

이제 P(0)=1에서 시작해 P(n) = P(n−1) + n을 펼쳐 일반식을 만드세요.

5-4토론

모둠에서 이야기해 봅시다

  1. 최대 조각이 나오려면 칼금들이 어떤 조건을 만족해야 하나요? 두 가지 금지 사항을 찾아 문장으로 쓰세요.
  2. "조각을 최대로 만드는 배치가 실제로 존재한다"는 것도 따로 보여야 할까요? 규칙을 세우는 것과 그런 배치를 그리는 것은 다른 일인가요?
  3. 1+2+3+…+n을 빠르게 더하는 방법을 알고 있나요? 그것이 왜 이 문제의 답에 나타날까요?
  4. 피자를 3차원 케이크로 바꿔 평면으로 자른다면 어떻게 될까요? 칼 3번으로 최대 몇 조각일지 예상하고 이유를 대 보세요.
5-5도전

직선 10개로 피자를 자를 때 최대 조각 수를 구하세요. 또, 100조각을 넘으려면 최소 몇 번 잘라야 하는지 구하세요.

출처 — Jakob Steiner(1826)의 평면 분할 문제. 수열 1, 2, 4, 7, 11, 16, 22, … 는 중심 다각수(OEIS A000124)로 불리며, 3차원판은 케이크 수열로 이어집니다.
