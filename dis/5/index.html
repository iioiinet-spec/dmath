모으고 겹치고
세어 보는 집합 5제

"모아 놓은 것"이라는 단순한 생각에서 출발해, 무한과 역설까지 걸어갑니다. 다섯 문제 모두 수학사에 이름을 남긴 고전이며, 답보다 왜 그런지 말로 설명하는 것이 목표입니다.

대상 초등 고학년 ~ 중등 세트 5개 문항 25개 (개별 20 · 토론 5) 권장 세트당 25~35분

이 문제집을 푸는 방법

STEP 1그림으로먼저 벤 다이어그램이나 표로 그려 봅니다.
STEP 2작게 줄여큰 수가 어려우면 3~4개로 줄여 손으로 셉니다.
STEP 3짝과 토론붉은 토론 문제를 서로 설득해 봅니다.
STEP 4이유 쓰기"왜냐하면"으로 시작하는 문장을 씁니다.

SET 01

둘 다 좋아하는 사람을 두 번 세지 않으려면

원전 · 오일러 다이어그램(1768)과 벤 다이어그램(John Venn, 1880) · 포함배제의 원리

난이도 ★☆☆합집합·교집합포함배제드 모르간
1-1탐색
상황 — 우리 반 40명에게 물었습니다. 축구를 좋아하는 사람 22명, 농구를 좋아하는 사람 18명, 둘 다 좋아하는 사람 9명.

22 + 18 = 40이니까 모두가 하나씩은 좋아하는 걸까요? 아래 벤 다이어그램의 숫자를 조절하며 네 영역이 어떻게 변하는지 보세요.

venn-two.svg
1-2추론

22 + 18을 그냥 더하면 무엇이 잘못될까요? 벤 다이어그램에서 가운데 부분이 몇 번 세어지는지 손가락으로 짚어 보세요.

  • 축구 22명 안에 "둘 다"인 9명이 들어 있나요?
  • 농구 18명 안에도 그 9명이 들어 있나요?
  • 그렇다면 22 + 18에서 그 9명은 몇 번 세어졌나요? 몇 번 빼야 할까요?
1-3확장
상황 — 이번엔 100명에게 세 가지를 물었습니다. 라면 58, 떡볶이 45, 김밥 32. 라면·떡볶이 둘 다 22, 떡볶이·김밥 둘 다 15, 김밥·라면 둘 다 18, 셋 다 8.

세 개짜리는 훨씬 까다롭습니다. 아래에서 7개 영역이 어떻게 채워지는지 안쪽부터 바깥으로 순서대로 확인하세요.

venn-three.svg
가운데(셋 다)부터 채워야 실수가 없습니다.
힌트 보기
셋 다인 8명은 세 원 각각에 들어 있어 3번 세어졌습니다. 두 개씩 빼면 3번 빠져서 0번이 되어 버립니다. 그래서 다시 한 번 더해 줍니다.
1-4토론

모둠에서 이야기해 봅시다

  1. 세 집합 공식에서 왜 더하고 → 빼고 → 다시 더하는 모양이 될까요? 셋 다인 사람이 각 단계에서 몇 번 세어지는지 표로 만들어 확인하세요.
  2. 어떤 학급에서 "축구 20명, 농구 15명, 둘 다 18명"이라는 조사 결과가 나왔습니다. 이 숫자는 가능한가요? 불가능하다면 어떤 규칙을 어겼나요?
  3. "라면을 안 좋아하고 떡볶이도 안 좋아하는 사람"과 "라면과 떡볶이를 둘 다 좋아하지는 않는 사람"은 같은 사람들인가요? 벤 다이어그램에 각각 칠해 보세요.
  4. 집합을 4개로 늘리면 원 4개로 모든 영역(16개)을 그릴 수 있을까요? 직접 그려 보고 왜 어려운지 이야기해 보세요.
1-5확인

토론 3번을 아래에서 직접 칠해 확인하세요. 두 표현이 같은지 다른지 눈으로 보고, 결론을 문장으로 적으세요.

de-morgan.svg

출처 — 원 그림으로 논리를 나타내는 방법은 레온하르트 오일러(1768)가 널리 알렸고, 오늘날 형태의 다이어그램은 존 벤(1880)이 정리했습니다. 포함배제의 원리는 이보다 앞서 드무아브르 등이 사용했습니다.

SET 02

토핑 6가지로 만들 수 있는 피자는 몇 종류

원전 · 멱집합(power set)과 2ⁿ — 집합론의 가장 기본적인 세기

난이도 ★★☆부분집합곱의 법칙파스칼 삼각형
2-1탐색
상황 — 피자 가게에 토핑이 6가지 있습니다. 각 토핑은 넣거나 넣지 않거나 둘 중 하나입니다. 같은 토핑을 두 번 넣을 수는 없습니다.

만들 수 있는 피자는 몇 종류일까요? 먼저 토핑을 2개, 3개로 줄여 직접 모두 적어 보세요.

power-set
3
2-2추론

왜 2ⁿ이 될까요? 토핑을 하나씩 결정해 나간다고 생각해 보세요.

  • 첫 번째 토핑을 넣을지 말지 정하는 방법은 몇 가지인가요?
  • 두 번째 토핑은? 세 번째는?
  • 토핑이 n개라면 전체 방법의 수는 어떻게 될까요?

이 방식으로 세면 0과 1로 된 번호표를 붙이는 것과 같아집니다. 위 도구에서 각 부분집합에 붙은 이진 번호를 확인하세요.

2-3발견

부분집합을 크기별로 나눠 세어 보면 어떤 수가 나올까요? 아래 표를 채우고 익숙한 삼각형을 찾아보세요.

pascal-count
먼저 직접 세어 본 뒤 버튼을 누르세요.
2-4토론

모둠에서 이야기해 봅시다

  1. 2ⁿ에는 아무 토핑도 안 넣은 피자(공집합)가 포함되어 있습니다. 이것도 한 종류로 세는 것이 옳을까요? 문제 상황에 따라 답이 달라질 수 있는지 이야기해 보세요.
  2. 특정 토핑(예: 치즈)이 반드시 들어간 피자는 몇 종류일까요? 세지 않고 답할 방법을 찾아보세요.
  3. 공집합의 부분집합은 몇 개일까요? 공집합의 멱집합은 공집합인가요, 아닌가요? 둘의 차이를 설명하세요.
  4. 토핑이 하나 늘어날 때마다 피자 종류가 2배가 됩니다. 왜 그럴까요? 새 토핑을 넣은 것과 안 넣은 것으로 나눠 설명해 보세요.
2-5도전

어떤 집합의 부분집합이 256개라고 합니다. 이 집합의 원소는 몇 개일까요? 또, 그 집합의 진부분집합(자기 자신을 뺀 것)은 몇 개일까요?

출처 — 멱집합의 크기가 2ⁿ이라는 사실은 집합론의 기본이며, 칸토어는 이를 무한집합으로 확장해 "어떤 집합보다 그 멱집합이 항상 더 크다"는 정리를 증명했습니다(칸토어의 정리, 1891).

SET 03

서울에 머리카락 수가 똑같은 사람이 있을까

원전 · 비둘기집 원리 (Dirichlet, 1834 · 서랍 원칙) — 세지 않고 존재를 증명하는 법

난이도 ★★☆존재 증명귀류법최악의 경우
3-1탐색
상황 — 캄캄한 방의 서랍에 검정 양말과 흰 양말이 잔뜩 섞여 있습니다. 불을 켤 수 없어 색을 볼 수 없습니다.

같은 색 한 켤레를 확실히 얻으려면 최소 몇 짝을 꺼내야 할까요? 아래에서 양말을 꺼내며 최악의 경우를 확인하세요.

pigeonhole
2
많은 사람이 틀리는 이유
"양말이 10짝씩 있으니 11짝은 꺼내야 한다"고 답하기 쉽습니다. 하지만 색은 두 종류뿐입니다. 세 번째 양말은 어떤 색이든 앞의 둘 중 하나와 짝이 됩니다.
3-2추론

이 원리를 한 문장으로 정리해 봅시다.

비둘기집 원리 — 비둘기 n마리를 비둘기집 m개에 넣을 때 n > m이면, 어떤 집에는 ___마리 이상이 들어간다.

왜 그럴까? 만약 모든 집에 1마리 이하만 있다면 전체 비둘기는 최대 ___마리다. 그런데 실제로는 n마리이고 n > m이므로 ___.
  • 13명이 모이면 같은 달에 태어난 두 사람이 반드시 있습니다. 왜일까요?
  • 8명이 모이면 같은 요일에 태어난 두 사람이 반드시 있습니다. 왜일까요?
  • 25명이 모이면 같은 달에 태어난 사람이 최소 몇 명 있을까요?
3-3도전
상황 — 서울 인구는 약 1000만 명입니다. 사람의 머리카락은 아무리 많아도 50만 올을 넘지 않는다고 합시다.

서울에 머리카락 수가 정확히 같은 두 사람이 반드시 있을까요? 아래에서 숫자를 바꿔 가며 확인하세요.

hair-count
3-4토론

모둠에서 이야기해 봅시다

  1. 비둘기집 원리는 같은 사람이 있다는 것만 알려 줄 뿐, 누구인지는 알려 주지 않습니다. 이런 증명을 어떻게 생각하나요? 쓸모가 있을까요?
  2. 양말 문제에서 "검정 한 켤레"를 확보하려면 몇 짝을 꺼내야 할까요? (검정 10짝, 흰색 10짝이 있다고 합시다.) 왜 답이 달라지나요?
  3. 모임에 온 사람들이 서로 악수를 했습니다. 악수한 횟수가 같은 두 사람이 반드시 있을까요? 3명, 4명으로 줄여 직접 확인해 보세요.
  4. 1부터 10까지 중에서 6개를 고르면, 그중 한 수가 다른 수를 나누는 쌍이 반드시 생깁니다. 왜일까요? (힌트: 각 수를 2로 계속 나눠 홀수를 만들어 보세요.)
divisor-pair-check
버튼을 눌러 210가지 경우를 모두 확인해 보세요.
3-5확장

우리 학교 학생이 500명이라면, 생일(2월 29일 제외 365일)이 같은 사람이 최소 몇 명 있을까요? 또, 생일이 같은 사람이 반드시 있으려면 최소 몇 명이 필요할까요?

출처 — 페터 구스타프 르죈 디리클레가 1834년 정수론 연구에서 사용해 "디리클레의 서랍 원칙(Schubfachprinzip)"으로 불립니다. 지극히 당연해 보이지만 존재를 증명하는 가장 강력한 도구 중 하나입니다.

SET 04

방이 무한한 호텔, 만실인데 손님을 더 받을 수 있을까

원전 · 힐베르트의 무한 호텔 (David Hilbert, 1924년 괴팅겐 강의) + 갈릴레오의 역설(1638)

난이도 ★★★일대일대응가산무한직관 깨기
4-1탐색
상황 — 1번, 2번, 3번, … 방이 끝없이 이어지는 호텔이 있습니다. 지금 모든 방에 손님이 한 명씩 들어 있어 빈방이 없습니다. 그런데 손님 한 명이 더 왔습니다.

돌려보내야 할까요? 아래에서 배정 방법을 실행해 보세요.

hilbert-hotel
4-2도전

이번엔 무한히 많은 손님을 태운 버스가 도착했습니다. 한 칸씩 옮기는 방법으로는 방 하나밖에 못 비웁니다. 어떻게 해야 할까요?

  • 기존 손님을 2배 번호 방으로 옮기면 어떤 방들이 비게 되나요?
  • 비는 방은 몇 개인가요? 유한한가요, 무한한가요?
  • 새 손님 m번째는 몇 번 방에 들어가면 될까요?
확인해야 할 두 가지
배정이 제대로 되려면 ① 겹치지 않아야 하고 ② 빠지는 방이 없어야 합니다. 짝수 방과 홀수 방이 이 두 조건을 만족하는지 확인하세요.
4-3발견
갈릴레오의 물음 (1638) — 자연수 1, 2, 3, 4, … 와 제곱수 1, 4, 9, 16, … 중 어느 쪽이 더 많을까요? 제곱수는 자연수의 일부인데, 짝을 지으면 하나도 남지 않습니다.

아래에서 두 줄을 나란히 놓고 짝지어 보세요. 그리고 1~N 안의 제곱수 비율이 어떻게 변하는지 관찰하세요.

galileo-paradox
4-4토론

모둠에서 이야기해 봅시다

  1. "모든 방이 찼다"와 "더 이상 손님을 받을 수 없다"는 같은 말인가요? 유한한 호텔과 무한한 호텔에서 각각 어떤가요?
  2. 제곱수는 자연수의 진부분집합인데 개수가 같습니다. 유한집합에서도 이런 일이 가능한가요? 무한집합의 정의를 여기서 만들어 볼 수 있을까요?
  3. 무한 버스가 무한 대로 왔습니다. 어떻게 해야 할까요? (힌트: 손님마다 버스 번호와 좌석 번호 두 개가 있습니다. 표를 그려 대각선으로 세어 보세요.)
  4. 그렇다면 모든 무한은 크기가 같을까요? 칸토어는 아니라고 답했습니다. 자연수보다 더 큰 무한이 있다면 어떤 것일지 상상해 보세요.
diagonal-order
(버스 번호, 좌석 번호) 쌍에 1, 2, 3, … 순번을 붙일 수 있을까요?
4-5정리

다음 집합들을 자연수와 짝지을 수 있는지(가산무한인지) 판단하고, 짝짓는 방법을 하나씩 적어 보세요.

  • 짝수 전체  ·  홀수 전체  ·  정수 전체(음수 포함)  ·  3의 배수 전체

출처 — 다비트 힐베르트가 1924년 1월 괴팅겐 강의에서 언급했고, 1948년 조지 가모프의 책 『1, 2, 3 그리고 무한』을 통해 널리 알려졌습니다. 자연수와 제곱수의 개수 문제는 갈릴레오 갈릴레이가 1638년 『새로운 두 과학』에서 제기했습니다.

SET 05

모든 사람의 수염을 깎는 이발사는 자기 수염을 깎을까

원전 · 러셀의 역설 (Bertrand Russell, 1901) — 집합론의 토대를 흔든 한 줄의 물음

난이도 ★★★자기지시모순정의의 힘
5-1탐색
상황 — 어느 마을에 이발사가 한 명 있습니다. 그는 "스스로 수염을 깎지 않는 사람"만, 그리고 그런 사람 전부의 수염을 깎습니다.

그렇다면 이발사 자신의 수염은 누가 깎을까요? 아래에서 두 경우를 각각 눌러 무슨 일이 생기는지 확인하세요.

barber-paradox
두 경우를 모두 눌러 보세요.
5-2추론

같은 문제를 집합으로 바꿔 봅시다. 집합은 보통 자기 자신을 원소로 갖지 않습니다. 예를 들어 "고양이들의 집합"은 고양이가 아니므로 자기 자신의 원소가 아닙니다.

러셀의 집합 — R = { 자기 자신을 원소로 갖지 않는 모든 집합 }

질문 : R은 R의 원소인가?

· R ∉ R 이라면 → R은 조건을 만족하므로 R의 원소여야 하고 → ___

이발사 이야기와 완전히 같은 구조임을 확인하세요. 무엇이 무엇에 대응되나요?

5-3비교

모든 자기지시가 문제를 일으키는 것은 아닙니다. 아래 문장들을 참·거짓·모순으로 분류해 보세요.

self-reference
문장을 눌러 하나씩 따져 보세요.
5-4토론

모둠에서 이야기해 봅시다

  1. "이 문장은 한국어로 쓰였다"는 자기 자신을 가리키지만 아무 문제가 없습니다. 그렇다면 어떤 자기지시가 모순을 만드나요? 두 종류를 비교해 규칙을 찾아보세요.
  2. 이발사 역설은 "그런 이발사는 없다"로 간단히 해결됩니다. 그런데 러셀의 집합은 왜 그렇게 넘어갈 수 없었을까요? 당시 수학자들이 무엇을 잃을까 봐 걱정했을지 이야기해 보세요.
  3. 수학자들은 결국 "조건을 쓰면 무엇이든 집합이 된다"는 생각을 버렸습니다. 대신 "이미 있는 집합에서 조건에 맞는 것만 골라낸다"로 규칙을 바꿨습니다. 이 변화가 왜 역설을 막을까요?
  4. "자기 자신을 포함하지 않는 모든 목록의 목록"을 백과사전에 실을 수 있을까요? 실으면 어떤 문제가 생기나요?
5-5도전

비슷한 구조의 문제를 직접 만들어 보세요. "○○하지 않는 모든 ○○를 ○○하는 ○○"의 빈칸을 채워, 모순이 생기는 이야기를 하나 지어 봅시다.
