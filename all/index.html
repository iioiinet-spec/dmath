명제 (Proposition)

예) "3은 소수이다" → T
역 · 이 · 대우
p→q의 변환 관계
역: q→p 이: ¬p→¬q 대우: ¬q→¬p
⭐ 원명제와 대우는 동치!
논리 연산자
∧ AND, ∨ OR, ¬ NOT, → 조건, ↔ 쌍조건
p→q ≡ ¬p∨q
드모르간 법칙
논리 연산 부정 변환
¬(p∧q) ≡ ¬p∨¬q
¬(p∨q) ≡ ¬p∧¬q
항진명제 vs 모순명제
항진: 모든 경우 T (예: p∨¬p)
모순: 모든 경우 F (예: p∧¬p)
동치 (≡)
두 명제의 진리표가 완전히 같을 때
p→q ≡ ¬p∨q ≡ ¬q→¬p

핵심 개념 정리
소수 (Prime Number)
1과 자기 자신만을 약수로 갖는 수
2, 3, 5, 7, 11, 13, ...
⭐ 2는 유일한 짝수 소수
소수 판별 최적화
n이 소수인지 확인할 때 √n까지만 나눠보면 충분
O(√n) 소수 판별
GCD (최대공약수)
유클리드 호제법: gcd(a,b) = gcd(b, a%b)
gcd(48,18): 48=18×2+12
gcd(18,12): 18=12×1+6
gcd(12,6): 12=6×2+0 → 6
LCM (최소공배수)
lcm(a,b) = a×b / gcd(a,b)
소인수분해
모든 자연수는 소수의 곱으로 유일하게 표현 가능
360 = 2³ × 3² × 5
약수의 개수
n = p₁^a₁ × p₂^a₂ × ... 일 때
약수의 개수 = (a₁+1)(a₂+1)...

조합론 (Combinatorics)
합·곱의 법칙 · 순열 · 조합 · 중복순열 · 중복조합
핵심 공식 정리
합의 법칙
두 사건이 동시에 일어나지 않을 때
|A| + |B|
곱의 법칙
두 사건이 독립적으로 연속 일어날 때
|A| × |B|
순열 P(n,r)
n개 중 r개를 순서 있게 선택
P(n,r) = n!/(n-r)!
조합 C(n,r)
n개 중 r개를 순서 없이 선택
C(n,r) = n!/(r!(n-r)!)
중복순열 Π(n,r)

nʳ
중복조합 H(n,r)

C(n,r) = C(n, n-r)  |  C(n,r) = C(n-1,r-1) + C(n-1,r)

그래프 이론

핵심 개념 정리
그래프 G = (V, E)
V: 정점(vertex)의 집합

차수 (Degree)
한 정점에 연결된 간선의 수
⭐ 모든 차수의 합 = 2|E| (악수 정리)
∑deg(v) = 2|E|
경로와 회로
경로: 정점과 간선의 연속열
단순경로: 정점 반복 없음
회로: 시작=끝 단순경로
오일러 경로/회로
모든 간선을 정확히 1번 지나는 경로/회로
오일러 회로: 홀수 차수 정점 = 0개
오일러 경로: 홀수 차수 정점 = 2개
트리 (Tree)
연결된 비순환 그래프
n개 정점 → n-1개 간선
임의의 두 정점 사이 경로 유일

함수와 관계
함수의 정의 · 단사·전사·전단사 · 이진관계 · 동치관계
핵심 개념 정리
함수 f: A→B
A의 모든 원소에 B의 원소를 하나씩 대응
정의역 A, 공역 B, 치역 f(A)⊆B
단사함수 (1-1)
서로 다른 입력 → 서로 다른 출력
f(a)=f(b) → a=b
|A| ≤ |B| 이어야 가능
전사함수 (onto)
공역과 치역이 같음
B의 모든 원소가 최소 1번 대응됨
|A| ≥ |B| 이어야 가능
전단사함수 (bijection)
단사 + 전사. 역함수 존재
|A| = |B| 이어야 가능
함수의 개수
|A|=m, |B|=n 일 때
전체 함수: nᵐ
단사 함수: P(n,m)
동치관계
반사적 + 대칭적 + 추이적 관계
동치류: 서로 관계된 원소의 집합
