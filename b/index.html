조합론 (Combinatorics)

경우의 수 핵심 이론 — 변별력 최고 영역 완전 정복

순열(Permutation) & 조합(Combination)

순서를 고려하면 순열, 고려하지 않으면 조합입니다.

기본 공식

// 순열: n개 중 r개를 순서있게
nPr = n! / (n-r)!

// 조합: n개 중 r개를 순서없이
nCr = n! / (r! × (n-r)!)
= nPr / r!

핵심: 조합 = 순열 ÷ r! (중복 순서 제거)

중복 순열 & 중복 조합

// 중복 순열: n개에서 r개 (반복 허용)
n^r (n의 r제곱)

// 중복 조합: n개에서 r개 (순서 무시, 반복 허용)
H(n,r) = C(n+r-1, r)
= (n+r-1)! / (r! × (n-1)!)

예: 동전 3종류에서 4개 선택 → H(3,4)=C(6,4)=15

C 언어 구현

long long fact(int n) { return n<=1?1:n*fact(n-1); }
long long perm(int n,int r) { return fact(n)/fact(n-r); }
long long comb(int n,int r) { return fact(n)/(fact(r)*fact(n-r)); }

// DP로 큰 조합 계산 (파스칼 삼각형)
long long C[101][101];
void build() {
for(int i=0;i<=100;i++) {
C[i][0]=C[i][i]=1;
for(int j=1;j<i;j++)
C[i][j]=C[i-1][j-1]+C[i-1][j]; // mod 필요 시 추가
}
}

계산기

파스칼 삼각형

C(n,r) = C(n-1,r-1) + C(n-1,r) — 노란 셀이 선택된 값

중복 종류별 비교 표

유형 공식 순서 중복 n=3,r=2 예
순열 nPr O X 6
조합 nCr X X 3
중복 순열 n^r O O 9
중복 조합 H(n,r) X O 6

포함과 배제의 원리

여러 집합의 합집합 원소 수를 구할 때, 중복 계산을 보정하는 원리입니다.

2개 집합

|A ∪ B| = |A| + |B| - |A ∩ B|

A와 B 모두에 속하는 원소를 한 번 빼줌

3개 집합

|A∪B∪C| =
|A|+|B|+|C|
-|A∩B|-|B∩C|-|A∩C|
+|A∩B∩C|

교집합은 빼고, 3중 교집합은 다시 더함

일반화 공식

|A₁∪A₂∪...∪Aₙ| =
Σ|Aᵢ|
- Σ|Aᵢ∩Aⱼ|
+ Σ|Aᵢ∩Aⱼ∩Aₖ|
- ... + (-1)^(n+1)|A₁∩A₂∩...∩Aₙ|

부호 규칙: 홀수 개 교집합은 +, 짝수 개는 −

시뮬레이터 — 1~N 중 k의 배수 제외

1부터 N까지의 수 중, 각 약수의 배수를 가지는 수의 개수 (포함-배제 적용)

대표 유형: 교란 순열(완전 순열)

n개를 배열할 때 어떤 원소도 원래 자리에 없는 경우의 수 D(n):

D(0)=1, D(1)=0
D(n) = (n-1) × (D(n-2) + D(n-1))
= n! × (1 - 1/1! + 1/2! - 1/3! + ...)

비둘기집의 원리 (Pigeonhole Principle)

n+1마리의 비둘기가 n개의 집에 들어갈 때, 반드시 2마리 이상이 같은 집에 있습니다.

기본 원리

비둘기 수 > 집의 수
⟹ 어떤 집에는 2마리 이상

더 일반적으로: n개 집에 kn+1개 비둘기 → 어떤 집에 k+1마리 이상

⌈(총 비둘기) / (집의 수)⌉ 마리 이상이
반드시 같은 집에 존재

대표 응용

생일 문제 367명 중 생일 같은 쌍 보장 (365+1)

수열 증가 n²+1개 수 중 길이 n+1 이상의 증가 또는 감소 부분수열 존재

나머지 n+1개의 정수 중 차가 n의 배수인 쌍 존재

그래프 n개 꼭짓점에서 각 차수 0~n-1 → 중복 차수 존재

시뮬레이터 — 비둘기 배치

예제 분석: 나머지 비둘기집

1부터 200까지의 수 중 51개를 선택하면, 반드시 한 수가 다른 수의 배수인 쌍이 존재합니다.

이유: 1~200의 모든 수는 홀수 × 2^k 로 표현
홀수 부분(1,3,5,...,199)은 100개
51 > 100/2 → 비둘기집 원리 적용
⟹ 같은 홀수 성분을 가진 두 수 존재
⟹ 한 수가 다른 수의 배수

점화식 (Recurrence Relation)

수열의 이전 항들로 다음 항을 정의하는 규칙입니다. DP의 핵심 개념입니다.

점화식 유형

1차 선형 a(n) = r × a(n-1)

피보나치형 F(n) = F(n-1) + F(n-2)

분할정복형 T(n) = 2T(n/2) + n

이항형 C(n,r) = C(n-1,r-1) + C(n-1,r)

하노이의 탑

H(1) = 1
H(n) = 2×H(n-1) + 1
= 2^n - 1

n개 원판 이동에 2ⁿ-1번 필요. 3개면 7번, 10개면 1023번!

피보나치 수열 시뮬레이터

F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2) — 파란색+초록색=보라색
