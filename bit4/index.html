비트(Bit)란 무엇인가?

컴퓨터는 모든 것을 0과 1로 저장합니다.
정수 하나를 32개의 칸(비트)으로 표현 → int = 32비트

🔢 10진수 → 2진수 변환기

( 0 ~ 255 )

👆 비트 직접 클릭해보기

아래 비트를 클릭하면 0↔1이 바뀌고 10진수 값이 변합니다.

📊 자릿값(가중치)

비트 번호 (i) 76543210
가중치 (2i) 1286432 1684 21
예시: 13 0000 11 01

13 = 8 + 4 + 1 = 2³ + 2² + 2⁰

핵심 비트 연산 공식

AND ( & ) — 둘 다 1이어야 1

A & B
int a = 12, b = 10;
int c = a & b; // 8

💡 특정 비트가 켜져 있는지 확인하는 데 사용

OR ( | ) — 하나라도 1이면 1

A | B
int c = a | b; // 14

💡 특정 비트를 켜는(Set) 데 사용

XOR ( ^ ) — 다르면 1, 같으면 0

A ^ B
int c = a ^ b; // 6

💡 비트 토글(켜↔끄기)에 사용

NOT ( ~ ) — 0과 1을 뒤집기

~A
int c = ~a; // C에서 -13 (부호비트 주의)

SHIFT ( << / >> ) — 비트 이동

A << k
A >> k
// 왼쪽 시프트 = × 2^k
int c = a << k;
// 오른쪽 시프트 = ÷ 2^k
int d = a >> k;

🔬 단일 비트 조작 공식 (k번째 비트)

목적공식결과
k번 비트 켜기 (Set) A | (1 << k)
k번 비트 끄기 (Clear) A & ~(1 << k)
k번 비트 반전 (Toggle) A ^ (1 << k)
k번 비트 확인 (Check) (A >> k) & 1

💻 코드로 보기

// 원소 i가 집합 S에 있는지 확인
if (S & (1 << i)) { /* 있음 */ }

// 원소 i를 집합에 추가
S |= (1 << i);

// 원소 i를 집합에서 제거
S &= ~(1 << i);

// 두 집합의 합집합 (Union)
int U = S1 | S2;

// 두 집합의 교집합 (Intersection)
int I = S1 & S2;

// S1에서 S2 빼기 (차집합)
int D = S1 & ~S2;

부분집합 열거 (Subset Enumeration)

핵심 트릭: S의 모든 부분집합을 순서대로 방문 
for (int sub = S; sub > 0; sub = (sub - 1) & S) {
    // sub는 S의 부분집합
    process(sub);
}
// 공집합(0)도 포함하려면:
for (int sub = S; ; sub = (sub - 1) & S) {
    process(sub);
    if (sub == 0) break;
}

원소 n개인 집합의 부분집합 수: 2ⁿ개

🎬 시각화 — 집합 S를 선택하세요

📐 왜 (sub-1) & S 인가?

예) S = 0111 (={A,B,C}), sub = 0110 (={B,C})

sub - 1 = 0101 → & S = 0101 (={A,C}) ← 다음 부분집합

sub-1은 sub의 가장 낮은 비트를 끄고 그 아래를 모두 1로 채웁니다.
& S는 S에 없는 비트를 제거합니다. → S 안에서만 순회!

비트마스크로 방문 체크

배열 visited[] 대신 정수 하나로 방문 여부 관리! 
// 기존 방법 (배열)
bool visited[N] = {false};
visited[i] = true;

// 비트마스크 방법 (정수 하나)
int visited = 0;
visited |= (1 << i);  // i번 방문
if (visited & (1 << i)) { /* 방문함 */ }

격자 크기 5×5 = 25칸, 각 칸을 비트 번호로 표현합니다.

① 비트마스크 DP — 외판원 문제 (TSP)

N개 도시를 모두 방문하는 최단 경로.
dp[visited][city] — visited: 방문한 도시 집합 (비트마스크), city: 현재 도시 

// 도시 수 N, 거리 dist[i][j]
int dp[1<<N][N]; // 2^N × N 테이블

for (int visited = 0; visited < (1<<N); visited++) {
  for (int cur = 0; cur < N; cur++) {
    if (!(visited & (1<<cur))) continue;
    for (int next = 0; next < N; next++) {
      if (visited & (1<<next)) continue; // 이미 방문
      int nv = visited | (1<<next);
      dp[nv][next] = min(dp[nv][next],
                         dp[visited][cur] + dist[cur][next]);
    }
  }
}

② 비트마스크로 부분집합 합 구하기

배열에서 합이 목표값인 부분집합 찾기 

int arr[] = {3, 1, 4, 2, 5};
int n = 5, target = 7;
for (int mask = 0; mask < (1<<n); mask++) {
    int sum = 0;
    for (int i = 0; i < n; i++)
        if (mask & (1<<i)) sum += arr[i];
    if (sum == target) print(mask);
}

③ popcount — 켜진 비트 수 세기

// C++ 내장 함수 (가장 빠름)
int cnt = __builtin_popcount(n);

// 직접 구현 (Brian Kernighan 알고리즘)
int countBits(int n) {
    int cnt = 0;
    while (n) { n &= (n - 1); cnt++; }
    return cnt;
}
// n &= (n-1) 은 가장 낮은 1비트를 끔!
