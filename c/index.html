그래프 기초 용어

그래프는 정점(Vertex)과 간선(Edge)으로 이루어진 자료구조입니다.

핵심 용어 정의

정점(Vertex/Node) 그래프의 기본 단위, 노드라고도 함

간선(Edge) 두 정점을 연결하는 선

차수(Degree) 한 정점에 연결된 간선의 수

경로(Path) 정점을 따라 이동하는 순서

사이클(Cycle) 시작점으로 돌아오는 경로

그래프 종류

무방향 그래프 간선에 방향 없음 (양방향)

방향 그래프(DAG) 간선에 방향 있음

가중치 그래프 간선에 비용(거리) 부여

연결 그래프 모든 정점이 연결됨

이분 그래프 두 집합으로 색칠 가능

인접 행렬 표현

int adj[V][V];
// adj[i][j]=1 이면 i→j 간선 존재
// 가중치 그래프: 가중치 값 저장
// 공간: O(V²), 조회: O(1)

밀집 그래프(간선 많음)에 유리

인접 리스트 표현

vector<int> adj[V];
// adj[i]에 i와 연결된 정점 저장
// 가중치: pair<int,int> 사용
// 공간: O(V+E), 순회: O(V+E)

희소 그래프(간선 적음)에 유리

인터랙티브 그래프 — 정점 클릭으로 차수 확인

정점을 클릭하면 해당 정점의 차수와 이웃을 확인할 수 있습니다.

DFS & BFS 탐색

그래프의 모든 정점을 체계적으로 방문하는 두 가지 핵심 알고리즘입니다.

DFS — 깊이 우선 탐색

갈 수 있는 한 깊이 파고들다가, 막히면 되돌아옵니다.

// 재귀 방식
bool visited[MAX];
void dfs(int v) {
visited[v] = true;
for (int u : adj[v])
if (!visited[u]) dfs(u);
}

자료구조: 스택(Stack) / 재귀 호출 스택

시간복잡도: O(V+E)

BFS — 너비 우선 탐색

가까운 정점부터 차례대로 방문합니다. 최단 거리 보장.

// 큐 방식
void bfs(int start) {
queue<int> q;
visited[start]=true; q.push(start);
while(!q.empty()) {
int v=q.front(); q.pop();
for(int u:adj[v])
if(!visited[u]){visited[u]=true;q.push(u);}
}
}

자료구조: 큐(Queue)

시간복잡도: O(V+E)

트리(Tree) & 순회

사이클이 없는 연결 그래프. V개 정점, V-1개 간선.

트리 용어

루트(Root) 최상위 정점 (부모 없음)

리프(Leaf) 자식이 없는 정점

깊이(Depth) 루트에서의 거리

높이(Height) 리프까지의 최대 거리

이진 트리 자식이 최대 2개

완전 이진 트리 특성

// 배열로 표현 (1-indexed)
부모(i) = i / 2
왼쪽(i) = 2 * i
오른쪽(i) = 2 * i + 1

// n개 노드 → 높이 = ⌊log₂n⌋
// 레벨 k → 최대 2^k개 노드

이진 트리 순회 시뮬레이터

전위(Pre): 루트→왼→오   중위(In): 왼→루트→오   후위(Post): 왼→오→루트

순회 결과:
순회 방법을 선택하세요

순회 C 코드

typedef struct Node { int val; Node *left, *right; } Node;

void preorder(Node* n) { if(!n)return; visit(n); preorder(n->left); preorder(n->right); }
void inorder(Node* n) { if(!n)return; inorder(n->left); visit(n); inorder(n->right); }
void postorder(Node* n) { if(!n)return; postorder(n->left); postorder(n->right); visit(n); }

최단 경로 — 다익스트라 알고리즘

가중치가 양수인 그래프에서 단일 시작점으로부터 모든 정점까지의 최단 거리를 구합니다.

알고리즘 핵심 아이디어

아직 방문하지 않은 정점 중 거리가 가장 짧은 정점을 선택해 이웃을 갱신(Relaxation)합니다.

dist[start] = 0; // 나머지 INF
while (미방문 정점 존재) {
v = dist 최솟값 미방문 정점;
visited[v] = true;
for (u in adj[v])
if(dist[v]+w(v,u) < dist[u])
dist[u] = dist[v]+w(v,u);
}

우선순위 큐 사용 시: O((V+E) log V)

주의사항 & 응용

음수 간선 사용 불가 → 벨만-포드 사용

단일 출발 한 정점에서 모든 정점

응용 네비게이션, 네트워크 라우팅

모든 쌍 최단 경로는 플로이드-워셜 O(V³) 사용

// 플로이드-워셜 핵심
for(k) for(i) for(j)
d[i][j]=min(d[i][j],d[i][k]+d[k][j]);

최소 신장 트리 — 크루스칼 알고리즘

모든 정점을 사이클 없이 연결하는 간선들의 집합 중, 가중치 합이 최소인 것입니다.

크루스칼 알고리즘

간선을 가중치 오름차순으로 정렬 후, 사이클을 형성하지 않는 간선을 탐욕적으로 선택합니다.

sort(edges by weight);
for (edge(u,v,w) in edges) {
if (find(u) != find(v)) { // 다른 집합
union(u, v); // 합치기
MST.add(edge);
}
}
// Union-Find 자료구조 활용
// 시간복잡도: O(E log E)

Union-Find (서로소 집합)

int parent[MAX];
int find(int x) {
if(parent[x]==x) return x;
return parent[x]=find(parent[x]); // 경로압축
}
void unite(int a, int b) {
a=find(a); b=find(b);
if(a!=b) parent[a]=b;
}

경로 압축으로 거의 O(1) 달성
